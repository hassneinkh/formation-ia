Leçon 1.7 · environ 4 h

JavaScript : fonctions, tableaux et objets

Objectif : ranger ton code dans des fonctions réutilisables, manipuler des listes de données (tableaux) et des fiches d'information (objets). Avec ces trois outils, tu peux représenter un vrai panier e-commerce, une liste de leçons ou de notes. C'est aussi exactement ce que React utilise partout.

Notion 1 — Les fonctions : des recettes réutilisables

C'est quoi ?

Une fonction est une recette avec un nom : tu l'écris une fois, puis tu l'utilises (tu l'« appelles ») autant de fois que tu veux, avec des ingrédients différents.

Comment l'écrire

// 1. DÉCLARER la fonction (écrire la recette)
function calculerTTC(prixHT, taux) {       // prixHT et taux = les PARAMÈTRES (les ingrédients)
  const tva = prixHT * taux / 100;
  return prixHT + tva;                     // return = le résultat que la fonction RENVOIE
}

// 2. APPELER la fonction (cuisiner) avec des ARGUMENTS (les vraies valeurs)
const prix1 = calculerTTC(100, 21);        // → 121
const prix2 = calculerTTC(50, 6);          // → 53
console.log(prix1, prix2);

La version courte : la fonction fléchée

const calculerTTC = (prixHT, taux) => {
  return prixHT + prixHT * taux / 100;
};

// Si le corps tient en UNE expression : encore plus court, le return est implicite
const doubler = (n) => n * 2;
console.log(doubler(4));   // → 8

Les deux écritures font la même chose. La fonction fléchée est très utilisée en React : apprends à la lire.

Quand créer une fonction ?

  • ✅ Quand tu fais la même chose à plusieurs endroits (règle : si tu copies-colles du code, fais-en une fonction).
  • ✅ Quand un bloc de code a un rôle clair qu'on peut nommer : calculerTotal, afficherMessage, estValide.
  • Nomme-la avec un verbe : elle fait quelque chose.

return ou console.log ?

console.log affiche pour toi, développeur. return renvoie une valeur que le reste du programme peut utiliser (la ranger dans une variable, l'additionner…). Une fonction de calcul doit presque toujours faire un return.

Erreurs fréquentes

  • Oublier le return : la fonction renvoie undefined.
  • Oublier les parenthèses à l'appel : calculerTTC (la recette elle-même) au lieu de calculerTTC(100, 21) (le résultat).
  • Écrire du code après le return : il n'est jamais exécuté, la fonction s'arrête au return.

Notion 2 — Les tableaux : des listes de valeurs

C'est quoi ?

Un tableau (array) est une liste ordonnée de valeurs, rangée dans une seule variable. Chaque valeur a une position, son indice, qui commence à 0.

Comment l'écrire

const villes = ["Bruxelles", "Liège", "Gand"];
//  indice :        0           1        2

console.log(villes[0]);       // → "Bruxelles" (le PREMIER est à l'indice 0)
console.log(villes.length);   // → 3 (le nombre d'éléments)
console.log(villes[villes.length - 1]);   // → "Gand" (le dernier)

villes.push("Namur");         // AJOUTE à la fin → ["Bruxelles", "Liège", "Gand", "Namur"]
villes.includes("Liège");     // → true (est-ce que la liste contient… ?)
villes.indexOf("Gand");       // → 2 (à quelle position ?)

Remarque : on peut faire push sur un tableau en const. const empêche de remplacer la boîte, pas d'ajouter dedans.

Parcourir un tableau

// for...of : « pour chaque ville dans villes »  ← le plus lisible
for (const ville of villes) {
  console.log(`J'aime ${ville}`);
}

// forEach : la même chose, avec une fonction
villes.forEach((ville) => console.log(ville));

Transformer et filtrer : map et filter

const prix = [10, 25, 40, 8];

// map : crée un NOUVEAU tableau en transformant CHAQUE élément
const prixTTC = prix.map((p) => p * 1.21);
// → [12.1, 30.25, 48.4, 9.68]

// filter : crée un NOUVEAU tableau avec seulement les éléments qui passent le test
const petitsPrix = prix.filter((p) => p < 20);
// → [10, 8]

// reduce : réduit tout le tableau à UNE valeur (ici la somme)
const total = prix.reduce((somme, p) => somme + p, 0);
// → 83   (0 = valeur de départ de la somme)

Quand utiliser quoi ?

Je veux…J'utilise
faire quelque chose avec chaque élément (afficher…)for...of ou forEach
transformer chaque élément en autre chosemap (React l'utilise pour afficher des listes !)
garder seulement certains élémentsfilter
calculer un total, une moyennereduce (ou une boucle avec un let)
savoir si un élément existeincludes

Erreurs fréquentes

  • villes[3] sur un tableau de 3 éléments → undefined (les indices vont de 0 à 2).
  • Croire que map ou filter modifient le tableau d'origine : ils en créent un nouveau. Range le résultat dans une variable.

Notion 3 — Les objets : des fiches d'information

C'est quoi ?

Un objet regroupe plusieurs informations sur une même chose, chacune avec un nom (sa propriété). Comme une fiche produit ou une carte d'identité.

Comment l'écrire

const produit = {
  nom: "Pizza Margherita",     // propriété: valeur,  ← virgule entre les propriétés
  prix: 11,
  vegetarien: true,
  ingredients: ["tomate", "mozzarella", "basilic"]   // une propriété peut être un tableau
};

console.log(produit.nom);          // → "Pizza Margherita"  (accès avec un point)
console.log(produit["prix"]);      // → 11  (accès avec des crochets : utile si le nom est dans une variable)
produit.prix = 12;                 // modifier une propriété
produit.enStock = true;            // ajouter une propriété

Le duo le plus important : un tableau d'objets

const lecons = [
  { numero: "0.1", titre: "Le terminal", terminee: true },
  { numero: "0.2", titre: "Git", terminee: true },
  { numero: "1.6", titre: "JavaScript", terminee: false }
];

// Combien de leçons terminées ?
const terminees = lecons.filter((lecon) => lecon.terminee);
console.log(`${terminees.length} / ${lecons.length} leçons terminées`);   // → 2 / 3

// La liste des titres
const titres = lecons.map((lecon) => lecon.titre);   // → ["Le terminal", "Git", "JavaScript"]

Retiens cette forme : presque toutes les données d'une application (produits, utilisateurs, messages, leçons) sont des tableaux d'objets. Quand tu recevras des données d'une API (Phase 2) ou de Supabase (Phase 3), elles auront cette forme.

Quand utiliser un tableau ou un objet ?

  • Tableau : une liste de choses du même genre (des villes, des produits). L'ordre compte, on parcourt.
  • Objet : les caractéristiques d'une seule chose (le nom, le prix… d'un produit). On accède par nom.

Erreurs fréquentes

  • Oublier la virgule entre deux propriétés → SyntaxError.
  • Cannot read properties of undefined (reading 'nom') → tu essaies de lire .nom sur quelque chose qui n'existe pas (par exemple lecons[5].nom sur un tableau de 3).

Notion 4 — Un avant-goût de JSON

Pour stocker ou envoyer un objet (dans le navigateur, à un serveur), on le transforme en texte au format JSON :

const texte = JSON.stringify(lecons);   // objet → texte
// '[{"numero":"0.1","titre":"Le terminal","terminee":true}, …]'
const retour = JSON.parse(texte);       // texte → objet

Tu t'en serviras dès la leçon 1.8 pour mémoriser des données, puis dans le projet de suivi de progression (1.9).

Exercice 1 — Tes premières fonctions

Ce qu'on attend de toi : 3 fonctions, chacune avec un return, testées avec console.log :

  • calculerTTC(prixHT, taux) → le prix TTC ;
  • estMajeur(age) → true si 18 ans ou plus ;
  • formaterPrix(montant) → un texte comme "12.50 €".

Bonus : combine-les : formaterPrix(calculerTTC(100, 21)) → "121.00 €".

Indice

Une comparaison donne déjà true/false : return age >= 18; suffit, pas besoin de if.

Correction (ouvre-la après avoir essayé) 
function calculerTTC(prixHT, taux) {
  return prixHT + prixHT * taux / 100;
}

function estMajeur(age) {
  return age >= 18;                 // la comparaison EST le résultat
}

const formaterPrix = (montant) => `${montant.toFixed(2)} €`;   // fléchée, return implicite

console.log(calculerTTC(100, 21));              // → 121
console.log(estMajeur(19), estMajeur(15));      // → true false
console.log(formaterPrix(12.5));                // → "12.50 €"
console.log(formaterPrix(calculerTTC(100, 21))); // → "121.00 €" : le résultat de l'une devient l'argument de l'autre

Exercice 2 — Le panier e-commerce

Ce qu'on attend de toi : un tableau panier de 4 objets { nom, prix, quantite }, puis :

  1. afficher chaque ligne : 2 x T-shirt — 39.98 € ;
  2. une fonction calculerTotal(panier) qui renvoie le total (prix × quantité pour chaque article) ;
  3. la liste des articles à moins de 20 € (avec filter) ;
  4. le total TTC formaté avec tes fonctions de l'exercice 1.

Comment vérifier : calcule le total à la main pour 2 articles et compare.

Indice 1

Pour chaque article du panier : article.prix * article.quantite.

Indice 2

Pour le total : un let total = 0; et une boucle for...of qui ajoute, ou un reduce.

Correction (ouvre-la après avoir essayé) 
const panier = [
  { nom: "T-shirt", prix: 19.99, quantite: 2 },
  { nom: "Casquette", prix: 14.5, quantite: 1 },
  { nom: "Sweat", prix: 49, quantite: 1 },
  { nom: "Stickers", prix: 3, quantite: 5 }
];

// 1. Afficher chaque ligne
for (const article of panier) {
  const sousTotal = article.prix * article.quantite;
  console.log(`${article.quantite} x ${article.nom} — ${sousTotal.toFixed(2)} €`);
}

// 2. Le total
function calculerTotal(articles) {
  let total = 0;
  for (const article of articles) {
    total += article.prix * article.quantite;
  }
  return total;
}
// Version reduce (même résultat) :
// const calculerTotal = (articles) => articles.reduce((s, a) => s + a.prix * a.quantite, 0);

// 3. Les articles à moins de 20 €
const petitsPrix = panier.filter((article) => article.prix < 20);
console.log(petitsPrix.map((article) => article.nom));   // → ["T-shirt", "Casquette", "Stickers"]

// 4. Total TTC formaté
const totalHT = calculerTotal(panier);
console.log(`Total TTC : ${formaterPrix(calculerTTC(totalHT, 21))}`);

À retenir : calculerTotal reçoit le panier en paramètre au lieu de lire directement la variable : elle marche avec n'importe quel panier.

Exercice 3 — Les statistiques de ta formation

Ce qu'on attend de toi : un tableau lecons avec les leçons 0.1 à 1.7 (objets { numero, titre, terminee }, en mettant true pour celles que tu as vraiment finies), puis afficher :

Leçons terminées : 6 / 11 (55 %)
Prochaine leçon : 1.3 — CSS : les bases

(Les chiffres dépendent de ce que tu as vraiment terminé.)

Indice

Le pourcentage : Math.round(terminees / total * 100). La prochaine : lecons.find((l) => !l.terminee) renvoie le premier élément qui passe le test.

Correction (ouvre-la après avoir essayé) 
const lecons = [
  { numero: "0.1", titre: "Le terminal", terminee: true },
  { numero: "0.2", titre: "Git", terminee: true },
  { numero: "0.3", titre: "GitHub", terminee: true },
  { numero: "0.4", titre: "VS Code et Claude Code", terminee: true },
  { numero: "1.1", titre: "HTML : la structure", terminee: true },
  { numero: "1.2", titre: "Liens, images, listes", terminee: true },
  { numero: "1.3", titre: "CSS : les bases", terminee: false },
  { numero: "1.4", titre: "Flexbox et grid", terminee: false },
  { numero: "1.5", titre: "Responsive", terminee: false },
  { numero: "1.6", titre: "JavaScript : les bases", terminee: false },
  { numero: "1.7", titre: "Fonctions, tableaux, objets", terminee: false }
];

const nbTerminees = lecons.filter((l) => l.terminee).length;
const pourcentage = Math.round(nbTerminees / lecons.length * 100);
console.log(`Leçons terminées : ${nbTerminees} / ${lecons.length} (${pourcentage} %)`);

const prochaine = lecons.find((l) => !l.terminee);   // ! = NON terminée
if (prochaine) {                                      // au cas où tout serait terminé
  console.log(`Prochaine leçon : ${prochaine.numero} — ${prochaine.titre}`);
} else {
  console.log("Tout est terminé, bravo !");
}

C'est exactement la logique que tu coderas pour de vrai dans le projet 1.9 (la barre de progression du site).

Ranger ton message de bienvenue dans une fonction

Ce qu'on attend de toi : dans site/js/main.js, transformer ton code de la leçon 1.6 en une fonction obtenirSalutation(heure) qui renvoie le texte, puis l'appeler pour l'afficher.

Correction (ouvre-la après avoir essayé) 
// Ma contribution (leçons 1.6 – 1.7)
function obtenirSalutation(heure) {
  if (heure < 12) {
    return "Bonjour";
  } else if (heure < 18) {
    return "Bon après-midi";

Questions pour vérifier que tu as compris

1. Quel est l'indice du premier élément d'un tableau ?

Réponse

0. Le dernier est à tableau.length - 1.

2. Différence entre map et filter ?

Réponse

map transforme chaque élément (même nombre d'éléments) ; filter garde ceux qui passent un test (souvent moins d'éléments).

3. Comment lire le prix de { nom: "Sweat", prix: 49 } rangé dans article ?

Réponse

article.prix

4. Une fonction sans return renvoie quoi ?

Réponse

undefined.
