Leçon 1.8 · environ 4 h

JavaScript : le DOM et les événements

Objectif : faire réagir une page. Trouver des éléments HTML depuis JavaScript, changer leur texte et leur style, en créer de nouveaux, réagir aux clics et à la saisie, et mémoriser des données dans le navigateur. Après cette leçon, tu pourras lire et comprendre site/js/main.js en entier.

Notion 1 — Le DOM : la page vue par JavaScript

C'est quoi ?

Quand le navigateur lit ton HTML, il construit un arbre d'objets : le DOM (Document Object Model). Chaque balise devient un objet que JavaScript peut lire et modifier. Si JavaScript modifie le DOM, la page change à l'écran, immédiatement.

document                     ← la page entière (l'objet de départ)
└─ html
   ├─ head
   └─ body
      ├─ header
      │  └─ h1  "Ma page"
      └─ main
         ├─ p   "Bonjour"
         └─ button "Clique-moi"

Tu vois ce même arbre dans F12 › Elements. C'est le DOM en direct : si JavaScript le change, l'onglet Elements change aussi.

Notion 2 — Trouver des éléments : querySelector

Comment l'écrire

// UN élément : le premier qui correspond (même syntaxe que les sélecteurs CSS !)
const titre = document.querySelector("h1");
const bouton = document.querySelector("#valider");      // par id
const carte = document.querySelector(".carte");         // la première .carte

// TOUS les éléments qui correspondent : une liste
const cartes = document.querySelectorAll(".carte");
console.log(cartes.length);                             // combien il y en a
cartes.forEach((c) => console.log(c));                 // on la parcourt comme un tableau

Quand utiliser lequel ?

  • querySelector : pour un élément précis (souvent avec un id ou une classe unique).
  • querySelectorAll : pour agir sur plusieurs éléments (tous les liens du menu, toutes les leçons).

Erreurs fréquentes

  • Cannot read properties of null → querySelector n'a rien trouvé (renvoie null) : faute dans le sélecteur, oubli du . ou du #, ou script chargé avant le HTML (mets <script> juste avant </body>).

Notion 3 — Modifier : texte, classes, attributs

Comment l'écrire

const titre = document.querySelector("h1");

titre.textContent = "Nouveau titre";        // change le TEXTE

titre.classList.add("important");           // ajoute une classe CSS
titre.classList.remove("important");        // l'enlève
titre.classList.toggle("important");        // l'ajoute si absente, l'enlève si présente (interrupteur)
titre.classList.contains("important");      // → true / false

const lien = document.querySelector("a");
lien.setAttribute("href", "parcours.html"); // change un attribut
lien.getAttribute("href");                  // le lit

Quand utiliser quoi ?

  • Changer l'apparence → classList, jamais le style directement. Le style reste dans le CSS, JavaScript ne fait qu'ajouter/enlever des classes.
  • Changer du texte → textContent.
  • innerHTML permet d'écrire du HTML (el.innerHTML = "<strong>Hi</strong>"), mais jamais avec un texte tapé par un utilisateur : il pourrait y glisser du code malveillant (faille XSS). Avec du texte utilisateur : textContent.

Notion 4 — Créer et supprimer des éléments

const liste = document.querySelector("#liste");

const nouvel = document.createElement("li");   // 1. créer (il n'est pas encore sur la page)
nouvel.textContent = "Acheter du pain";       // 2. le remplir
nouvel.classList.add("tache");
liste.appendChild(nouvel);                    // 3. l'ajouter à la fin de la liste → il apparaît

nouvel.remove();                              // le supprimer de la page
liste.innerHTML = "";                         // vider complètement un élément

Le schéma classique : afficher un tableau de données

const villes = ["Bruxelles", "Liège", "Gand"];
const ul = document.querySelector("#villes");

function afficherVilles() {
  ul.innerHTML = "";                         // 1. on vide
  for (const ville of villes) {             // 2. on recrée un li par donnée
    const li = document.createElement("li");
    li.textContent = ville;
    ul.appendChild(li);
  }
}
afficherVilles();

Retiens ce schéma « données → affichage » : les données (le tableau) sont la vérité ; on vide et on redessine. React (Phase 3) fait exactement ça… automatiquement.

Notion 5 — Les événements : réagir à l'utilisateur

C'est quoi ?

Un événement est quelque chose qui se passe : un clic, une touche, une saisie, un défilement. Tu peux « écouter » un événement et lancer une fonction quand il arrive.

Comment l'écrire

const bouton = document.querySelector("#mon-bouton");

bouton.addEventListener("click", () => {     // "quand on clique sur le bouton, fais ceci"
  console.log("Cliqué !");
});
//                       ↑ le type d'événement   ↑ la fonction à lancer
ÉvénementQuandExemple d'usage
clickclic sur l'élémentboutons, cases à cocher
inputchaque changement dans un champrecherche en direct, compteur de caractères
changecase cochée/décochée, choix validécases à cocher, listes déroulantes
submitenvoi d'un formulaireformulaires (leçon 1.10)
keydownune touche enfoncéeraccourcis clavier
scrolldéfilement de la pagebouton « haut de page »

L'objet événement et la valeur d'un champ

const champ = document.querySelector("#prenom");     // un <input id="prenom">
const apercu = document.querySelector("#apercu");

champ.addEventListener("input", (evenement) => {    // la fonction reçoit l'événement
  apercu.textContent = `Bonjour ${champ.value}`;     // .value = ce qui est écrit dans le champ
});

Erreurs fréquentes

  • addEventListener("click", direBonjour()) avec des parenthèses : la fonction s'exécute tout de suite, une seule fois. Il faut donner la fonction elle-même : addEventListener("click", direBonjour).
  • "onclick" au lieu de "click" : avec addEventListener, pas de « on ».
  • champ.value est toujours du texte, même si on tape un nombre → Number(champ.value) pour calculer.

Notion 6 — Mémoriser : localStorage

C'est quoi ?

Une petite mémoire du navigateur, propre à ton site, qui survit au rechargement et à la fermeture de la page. Elle stocke uniquement du texte.

Comment l'écrire

localStorage.setItem("prenom", "Hassnein");          // enregistrer (clé, valeur)
const prenom = localStorage.getItem("prenom");       // lire → "Hassnein" (ou null si rien)
localStorage.removeItem("prenom");                   // effacer

// Pour un tableau ou un objet : JSON (leçon 1.7)
const taches = ["Leçon 1.8", "Commit"];
localStorage.setItem("taches", JSON.stringify(taches));            // tableau → texte
const relues = JSON.parse(localStorage.getItem("taches")) || [];   // texte → tableau ; [] si rien encore

Quand l'utiliser ?

  • ✅ Préférences et petites données personnelles : thème choisi, cases cochées, brouillons, ta progression.
  • ❌ Données importantes ou partagées : elles restent sur ce navigateur, cet ordinateur, et disparaissent si on vide les données du site. Pour ça : une base de données (Supabase, Phase 3).
  • ❌ Jamais de mot de passe ni de donnée sensible.

Voir le contenu : F12 › onglet Application (ou Stockage) › Local Storage.

Notion 7 — Relire site/js/main.js

Tu as maintenant tout ce qu'il faut. Le code de départ du site :

const pageActuelle = window.location.pathname.split("/").pop() || "index.html";
// window.location.pathname = l'adresse de la page, ex. "/site/parcours.html"
// .split("/") = découpe en tableau à chaque "/" → ["", "site", "parcours.html"]
// .pop() = prend le dernier élément → "parcours.html" ; || "index.html" si c'est vide

const liensMenu = document.querySelectorAll(".nav a");     // tous les liens du menu (notion 2)

liensMenu.forEach(function (lien) {                         // pour chaque lien…
  const cible = lien.getAttribute("href").split("/").pop(); // …le nom du fichier visé (notion 3)
  if (cible === pageActuelle) {                             // si c'est la page actuelle…
    lien.classList.add("actif");                            // …on ajoute la classe "actif" (le CSS la colore)
  }
});

Exercices

Préparation : exercices/module-1-8/ avec un index.html, un style.css et un script.js, tous reliés. Chaque exercice ajoute un bout de HTML dans index.html et le code correspondant dans script.js.

Exercice 1 — Le compteur de clics

Ce qu'on attend de toi : un texte « Clics : 0 » et deux boutons « +1 » et « Remettre à zéro ». Le texte se met à jour à chaque clic. À partir de 10 clics, le texte devient rouge (via une classe CSS .beaucoup).

Indice 1

Un let compteur = 0; pour la donnée, et une fonction afficher() qui met à jour le texte et la classe.

Indice 2

Pour la classe : classList.toggle("beaucoup", compteur >= 10) — avec un 2e argument, toggle ajoute si c'est vrai et enlève si c'est faux.

Correction (ouvre-la après avoir essayé) 
<p id="affichage">Clics : 0</p>
<button id="plus">+1</button>
<button id="reset">Remettre à zéro</button>
.beaucoup { color: #e11d48; font-weight: 700; }
// 1. Les éléments
const affichage = document.querySelector("#affichage");
const boutonPlus = document.querySelector("#plus");
const boutonReset = document.querySelector("#reset");

// 2. La donnée
let compteur = 0;

// 3. L'affichage : met la page en accord avec la donnée
function afficher() {
  affichage.textContent = `Clics : ${compteur}`;
  affichage.classList.toggle("beaucoup", compteur >= 10);
}

// 4. Les événements : changent la donnée, puis réaffichent
boutonPlus.addEventListener("click", () => {
  compteur++;
  afficher();
});

boutonReset.addEventListener("click", () => {
  compteur = 0;
  afficher();
});

Le schéma à retenir (le même dans tous les exercices) : éléments → donnée → fonction d'affichage → événements qui modifient la donnée et réaffichent.

Exercice 2 — L'aperçu de carte de visite

Ce qu'on attend de toi : deux champs (<input>) « Prénom » et « Métier », et une carte qui affiche en direct « Hassnein — Développeur web » pendant la saisie. Sous les champs : « 12 / 30 caractères » pour le métier.

Indice

Événement input sur chaque champ, .value pour lire, .length pour compter les caractères d'un texte.

Correction (ouvre-la après avoir essayé) 
<label for="prenom">Prénom</label>
<input id="prenom" type="text">
<label for="metier">Métier</label>
<input id="metier" type="text" maxlength="30">
<p id="compteur-metier">0 / 30 caractères</p>
<div class="carte-visite"><p id="apercu">Ton nom — ton métier</p></div>
const champPrenom = document.querySelector("#prenom");
const champMetier = document.querySelector("#metier");
const apercu = document.querySelector("#apercu");
const compteurMetier = document.querySelector("#compteur-metier");

function mettreAJour() {
  const prenom = champPrenom.value || "Ton nom";     // || : texte par défaut si le champ est vide
  const metier = champMetier.value || "ton métier";
  apercu.textContent = `${prenom} — ${metier}`;      // textContent : sûr avec du texte tapé
  compteurMetier.textContent = `${champMetier.value.length} / 30 caractères`;
}

champPrenom.addEventListener("input", mettreAJour);  // sans parenthèses : on DONNE la fonction
champMetier.addEventListener("input", mettreAJour);

<label for="…"> relie le texte au champ (cliquer sur le texte active le champ) : important pour l'accessibilité. On le reverra en 1.10.

Exercice 3 — La liste de tâches qui se souvient

Ce qu'on attend de toi : un champ, un bouton « Ajouter » et une liste <ul>.

  • « Ajouter » crée une tâche (ignorer si le champ est vide), vide le champ ;
  • chaque tâche a un bouton « ✕ » qui la supprime ;
  • après un rechargement de la page (F5), les tâches sont toujours là.

Comment vérifier : ajoute 3 tâches, supprime la 2e, recharge : il en reste 2. F12 › Application › Local Storage montre la clé taches.

Indice 1 : l'organisation

Un tableau taches (la donnée), une fonction sauvegarder() (tableau → localStorage), une fonction afficher() (tableau → page). Chaque action modifie le tableau, puis appelle sauvegarder() et afficher().

Indice 2 : supprimer

Dans afficher(), en créant le bouton ✕ de la tâche numéro i, ajoute-lui un écouteur qui fait taches.splice(i, 1) (retire 1 élément à la position i).

Correction (ouvre-la après avoir essayé) 
<input id="nouvelle-tache" type="text" placeholder="Nouvelle tâche">
<button id="ajouter">Ajouter</button>
<ul id="liste-taches"></ul>
// 1. Les éléments
const champ = document.querySelector("#nouvelle-tache");
const boutonAjouter = document.querySelector("#ajouter");
const liste = document.querySelector("#liste-taches");

// 2. La donnée : relue depuis la mémoire du navigateur, ou un tableau vide
let taches = JSON.parse(localStorage.getItem("taches")) || [];

// 3. Enregistrer
function sauvegarder() {
  localStorage.setItem("taches", JSON.stringify(taches));
}

// 4. Afficher : on vide, puis on recrée un <li> par tâche
function afficher() {
  liste.innerHTML = "";
  taches.forEach((tache, i) => {          // forEach donne aussi la position i
    const li = document.createElement("li");
    li.textContent = tache;

    const boutonSuppr = document.createElement("button");
    boutonSuppr.textContent = "✕";
    boutonSuppr.addEventListener("click", () => {
      taches.splice(i, 1);                 // retire la tâche n° i du tableau
      sauvegarder();
      afficher();
    });

    li.appendChild(boutonSuppr);
    liste.appendChild(li);
  });
}

// 5. Ajouter
boutonAjouter.addEventListener("click", () => {
  const texte = champ.value.trim();        // trim() enlève les espaces au début et à la fin
  if (texte === "") {
    return;                                // champ vide : on ne fait rien
  }
  taches.push(texte);
  champ.value = "";
  sauvegarder();
  afficher();
});

// 6. Au chargement de la page : afficher ce qui était mémorisé
afficher();

Félicitations : tu viens d'écrire une vraie petite application. Le journal (1.10) utilisera exactement cette structure.

🔧 Ajout au site (ta part du 50/50)

Le bouton « Haut de page »

Ce qu'on attend de toi : dans site/js/main.js, créer en JavaScript un bouton « ↑ » ajouté à toutes les pages, fixé en bas à droite, invisible en haut de page, qui apparaît quand on a défilé de plus de 400px, et qui remonte en haut au clic. Le style est dans site/css/style.css, avec les variables du site.

Indice 1

document.createElement("button") puis document.body.appendChild(…). La position de défilement : window.scrollY.

Indice 2

Une classe .visible ajoutée/retirée avec classList.toggle("visible", window.scrollY > 400) dans un écouteur scroll sur window. Pour remonter : window.scrollTo({ top: 0, behavior: "smooth" }).

Correction (ouvre-la après avoir essayé) 
// Ma contribution (leçon 1.8) : bouton "haut de page"
const boutonHaut = document.createElement("button");
boutonHaut.textContent = "↑";
boutonHaut.className = "bouton-haut";
boutonHaut.setAttribute("aria-label", "Revenir en haut de la page");   // texte lu par les lecteurs d'écran
document.body.appendChild(boutonHaut);

window.addEventListener("scroll", () => {
  boutonHaut.classList.toggle("visible", window.scrollY > 400);
});

boutonHaut.addEventListener("click", () => {
  window.scrollTo({ top: 0, behavior: "smooth" });
});
/* Ma contribution (leçon 1.8) */
.bouton-haut {
  position: fixed;          /* reste au même endroit de l'écran pendant le défilement */
  right: 20px;
  bottom: 20px;
  width: 44px;
  height: 44px;
  border: none;
  border-radius: 50%;
  background: var(--accent);
  color: #fff;
  font-size: 1.2rem;
  cursor: pointer;
  opacity: 0;               /* invisible… */
  pointer-events: none;     /* …et non cliquable */

}
.bouton-haut.visible {
  opacity: 1;

}

Questions pour vérifier que tu as compris

1. document.querySelector(".menu") renvoie null. Cite 2 causes possibles.

Réponse

Aucun élément n'a la classe menu (faute, ou oubli du point) ; ou le script s'exécute avant que le HTML soit chargé (balise script mal placée).

2. Pour rendre un élément rouge depuis JavaScript, que fais-tu ?

Réponse

Je crée une classe dans le CSS et je l'ajoute avec classList.add(…). Le style reste dans le CSS.

3. Pourquoi JSON.stringify avant localStorage.setItem pour un tableau ?

Réponse

Parce que localStorage ne stocke que du texte : on transforme le tableau en texte, puis JSON.parse pour le relire.

4. Pourquoi textContent plutôt que innerHTML pour afficher ce qu'un visiteur a tapé ?

Réponse

innerHTML interprète le HTML : un visiteur pourrait injecter du code malveillant. textContent affiche le texte tel quel.

  • Je change un texte et des classes, je lis et modifie des attributs.
  • Je crée, ajoute et supprime des éléments.
  • J'écoute des événements (click, input, scroll) et je lis .value.
  • Je mémorise un tableau avec localStorage et JSON.
  • Je comprends chaque ligne de site/js/main.js.
