Leçon 0.1 · environ 1 h 30

Le terminal : piloter ton ordinateur au clavier

Objectif : à la fin de cette leçon, tu sais te déplacer dans tes dossiers, créer des dossiers et des fichiers, et lire leur contenu, uniquement avec des commandes.

Pourquoi le terminal ?

Le terminal, c'est une fenêtre où tu écris des ordres à ton ordinateur au lieu de cliquer. Tous les outils de développeur s'utilisent ainsi : Git, Node.js, Next.js, Expo… et même Claude Code lance des commandes dans un terminal quand il travaille pour toi. Comprendre le terminal, c'est comprendre ce que fait l'IA à ta place.

Ouvrir Git Bash

Sur Windows, on utilise Git Bash, installé avec Git (déjà présent sur ton PC). Il accepte les mêmes commandes que Mac et Linux : ce que tu apprends ici marche partout.

  1. Appuie sur la touche Windows et tape Git Bash.
  2. Ouvre-le. Tu vois une ligne qui finit par $ : c'est l'invite. Le terminal attend ton ordre.

Les commandes essentielles

Tu tapes une commande, puis tu appuies sur Entrée.

CommandeCe qu'elle faitMoyen mnémotechnique
pwdAffiche le dossier où tu te trouvesprint working directory
lsListe le contenu du dossierlist
cd nomEntre dans le dossier « nom »change directory
cd ..Remonte d'un dossier.. = le dossier parent
cd ~Revient à ton dossier personnel~ = la maison
mkdir nomCrée un dossiermake directory
touch nom.txtCrée un fichier vide« toucher » un fichier le fait exister
cat nom.txtAffiche le contenu d'un fichierconcatenate
clearNettoie l'écran
# Exemple : aller dans ton projet de formation
cd ~/Documents/formation-ia
pwd
# → /c/Users/hsnyt/Documents/formation-ia
ls
# → CLAUDE.md  PROGRESSION.md  README.md  exercices  journal.md  projets  site

Deux super-pouvoirs :

  • Tab : tape le début d'un nom (cd Docu) puis Tab, et le terminal complète tout seul.
  • Flèche du haut : rappelle les commandes précédentes, pour ne pas tout retaper.

Attention aux espaces. Pour le terminal, un espace sépare deux choses. Un dossier nommé Mes projets doit s'écrire entre guillemets : cd "Mes projets". C'est pour ça que les développeurs nomment leurs fichiers avec-des-tirets.

Écrire dans un fichier

echo "Bonjour" > salut.txt     # crée (ou remplace) le fichier avec ce texte
echo "Deuxième ligne" >> salut.txt   # ajoute une ligne à la fin
cat salut.txt

Exercices

Exercice 1 — Se repérer

  1. Ouvre Git Bash et tape pwd. Où es-tu ?
  2. Tape ls. Reconnais-tu les dossiers ?
  3. Va dans Documents/formation-ia en utilisant la touche Tab.
  4. Entre dans site, puis liste son contenu. Remonte ensuite d'un niveau.

Exercice 2 — Construire avec des commandes

Depuis formation-ia, et sans utiliser la souris :

  1. Crée le dossier exercices/module-0-1.
  2. Entre dedans et crée un fichier commandes.txt.
  3. Écris dedans, une ligne à la fois, les 3 commandes que tu trouves les plus utiles.
  4. Affiche le fichier pour vérifier.
Indice

Tu as besoin de mkdir, cd, echo … >> et cat. Pour créer un dossier dans un autre dossier : mkdir exercices/module-0-1.

Exercice 3 — Vérifier avec Claude

Dans Claude Code, écris : « J'ai fini l'exercice 2 de la leçon 0.1, peux-tu vérifier mon fichier ? » Claude va lire ton fichier et te donner un retour.

Checklist

  • Je sais ouvrir Git Bash.
  • Je sais où je suis (pwd) et ce qu'il y a autour (ls).
  • Je me déplace avec cd, cd .. et cd ~.
  • Je crée des dossiers et des fichiers (mkdir, touch, echo).
  • J'utilise Tab et la flèche du haut.
