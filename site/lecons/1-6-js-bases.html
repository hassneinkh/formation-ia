Leçon 1.6 · environ 4 h

JavaScript : variables, conditions et boucles

Objectif : écrire tes premiers programmes. Stocker des informations dans des variables, faire des calculs, prendre des décisions avec des conditions, répéter des actions avec des boucles, et lire les erreurs dans la console.

Pourquoi JavaScript ?

HTML = la structure, CSS = l'apparence, JavaScript = le comportement. C'est le seul langage de programmation que tous les navigateurs comprennent. Et c'est la base de tout ce qui t'attend : React (Phase 3), les apps mobiles (Phase 7), et les produits IA (Phase 5) s'écrivent en JavaScript. C'est la leçon la plus importante de la Phase 1.

Notion 1 — Où écrire du JavaScript, et la console

C'est quoi ?

Le JavaScript s'écrit dans un fichier .js, relié à la page HTML. Le navigateur l'exécute ligne par ligne, de haut en bas.

Comment l'écrire

<!-- index.html : juste avant </body> -->
  <script src="script.js"></script>
</body>
// script.js
console.log("Bonjour depuis JavaScript !");   // affiche un message dans la console

Pourquoi juste avant </body> ? Pour que tout le HTML soit déjà chargé quand le script s'exécute (important en leçon 1.8).

La console : ton tableau de bord

F12 › onglet Console. Tu y vois :

  • ce que tu affiches avec console.log(…) — ton outil n°1 pour comprendre ce que fait ton code ;
  • les erreurs en rouge, avec le fichier et le numéro de ligne (par exemple script.js:12) ;
  • une ligne où tu peux taper du JavaScript directement pour tester : essaie 2 + 2 puis Entrée.

Les commentaires

// Commentaire sur une ligne
/* Commentaire
   sur plusieurs lignes */

Erreurs fréquentes

  • Rien ne se passe : le fichier n'est pas relié (vérifie le src), ou tu ne regardes pas la console.
  • <script src="script.js"/> : la balise script doit toujours être fermée par </script>.

Notion 2 — Les variables : const et let

C'est quoi ?

Une variable, c'est une boîte avec une étiquette : tu ranges une valeur dedans et tu la retrouves avec son nom.

Comment l'écrire

const prenom = "Hassnein";   // const : la valeur ne changera PAS
let age = 19;                // let : la valeur PEUT changer
age = 20;                    // on remplace la valeur (sans re-écrire let)
console.log(prenom, age);    // → Hassnein 20

Anatomie : const (le mot-clé) · prenom (le nom) · = (« reçoit », pas « égale ») · "Hassnein" (la valeur) · ; (fin de l'instruction).

Quand utiliser const ou let ?

  • Par défaut : const. La plupart des valeurs ne changent pas, et ça évite les erreurs.
  • let seulement si tu sais que la valeur va changer : un compteur, un total qui augmente.
  • var : l'ancienne façon. Tu la verras dans de vieux tutoriels ; ne l'utilise pas.

Bien nommer

En camelCase (première lettre en minuscule, chaque nouveau mot en majuscule), un nom qui dit ce que contient la boîte : prixTotal, nombreDeLecons, estConnecte. Pas x, truc, ni d'espace ou de tiret.

Erreurs fréquentes

  • TypeError: Assignment to constant variable → tu essaies de changer une const. Utilise let si elle doit changer.
  • ReferenceError: prenon is not defined → faute de frappe dans le nom, ou variable pas encore créée. JavaScript respecte les majuscules : Prenom ≠ prenom.

console.log(typeof "19");   // → "string"  (entre guillemets = du texte !)
console.log(typeof 19);     // → "number"

Assembler du texte : les template strings

const prenom = "Hassnein";
const age = 19;
// Avec des accents graves ` (clavier belge : AltGr + touche µ, à gauche d'Entrée ; clavier français : AltGr + 7 ; puis espace)
const phrase = `Je m'appelle ${prenom} et j'ai ${age} ans.`;
console.log(phrase);        // → Je m'appelle Hassnein et j'ai 19 ans.

Quand ? Dès que tu mélanges du texte et des variables. ${…} insère la valeur. C'est plus lisible que "Je m'appelle " + prenom + "…".

Erreurs fréquentes

  • "5" + 3 donne "53" (du texte collé), pas 8 ! Un nombre entre guillemets est du texte. Convertis avec Number("5").
  • 12,5 au lieu de 12.5 : en code, la décimale est un point.

Notion 4 — Les opérateurs : calculer et comparer

Calculer

const prixHT = 100;
const tva = prixHT * 0.21;          // * multiplier  → 21
const prixTTC = prixHT + tva;       // + additionner → 121
const parPersonne = prixTTC / 4;    // / diviser     → 30.25
const reste = 10 % 3;               // % reste de la division → 1 (pratique pour pair/impair)

let compteur = 0;
compteur = compteur + 1;            // augmenter de 1…
compteur += 1;                      // …en plus court
compteur++;                         // …encore plus court → compteur vaut 3

Comparer (le résultat est true ou false)

OpérateurSensExemple → résultat
===strictement égalage === 19 → true
!==différentville !== "Liège" → true
> < >= <=plus grand, plus petit…age >= 18 → true
&&ET (les deux vrais)age >= 18 && aPermis
||OU (au moins un vrai)estSamedi || estDimanche
!NON (inverse)!estTermine

Erreurs fréquentes

  • = au lieu de === dans une comparaison : = range une valeur, === compare.
  • == (deux signes) : il compare de façon « souple » ("5" == 5 donne true). Utilise toujours ===.

Notion 5 — Les conditions : if, else if, else

C'est quoi ?

Faire une chose ou une autre selon une situation : « si le panier dépasse 30 €, la livraison est gratuite, sinon elle coûte 4,90 € ».

Comment l'écrire

const total = 42;

if (total >= 30) {                  // la condition, entre parenthèses
  console.log("Livraison gratuite"); // exécuté si la condition est vraie
} else {
  console.log("Livraison : 4,90 €"); // exécuté sinon
}

// Plusieurs cas : else if, testés DANS L'ORDRE, le premier vrai gagne
const note = 14;
if (note >= 16) {
  console.log("Grande distinction");
} else if (note >= 14) {
  console.log("Distinction");        // ← celui-ci (16 est faux, 14 est vrai)
} else if (note >= 10) {
  console.log("Réussi");
} else {
  console.log("Échec");
}

Quand l'utiliser ?

Dès que ton programme doit réagir différemment : un formulaire mal rempli, un utilisateur connecté ou non, une case cochée ou non.

Erreurs fréquentes

  • Mauvais ordre des else if : si tu testes note >= 10 en premier, un 18 affiche « Réussi ». Va du plus exigeant au moins exigeant.
  • Oublier une accolade } : SyntaxError: Unexpected end of input. L'indentation t'aide à voir ce qui manque.

Notion 6 — Les boucles : for et while

C'est quoi ?

Répéter une action sans copier-coller le code : afficher 10 lignes, parcourir 69 leçons, compter jusqu'à 100.

La boucle for : quand tu sais combien de fois

for (let i = 1; i <= 5; i++) {
  console.log(`Tour numéro ${i}`);
}
//   let i = 1  → DÉPART : un compteur i commence à 1
//   i <= 5     → CONDITION : on continue tant que i vaut 5 ou moins
//   i++        → ÉTAPE : après chaque tour, i augmente de 1
// Affiche : Tour numéro 1, Tour numéro 2, … Tour numéro 5

La boucle while : quand tu ne sais pas combien de fois

let epargne = 0;
let mois = 0;
while (epargne < 1000) {    // tant que l'objectif n'est pas atteint…
  epargne += 150;           // …j'épargne 150 € par mois
  mois++;
}
console.log(`Objectif atteint en ${mois} mois`);   // → 7 mois

Combiner boucle et condition

for (let i = 1; i <= 10; i++) {
  if (i % 2 === 0) {                    // reste de la division par 2 = 0 → pair
    console.log(`${i} est pair`);
  }
}

Erreurs fréquentes

  • La boucle infinie : une condition qui ne devient jamais fausse (oublier i++ ou epargne += …). La page se fige : ferme l'onglet, corrige, rouvre.
  • Décalage de un : i < 5 fait 4 tours si on part de 1. Vérifie avec un console.log(i).

Exemple complet : le calculateur de commande

// Données de la commande
const prixPizza = 12.5;
const quantite = 3;
const estEtudiant = true;

// Calculs
let total = prixPizza * quantite;            // 37.5
if (estEtudiant) {
  total = total * 0.9;                       // -10 % étudiant → 33.75
}

// Livraison
let livraison = 4.9;
if (total >= 30) {
  livraison = 0;
}

// Résultat
console.log(`Sous-total : ${total.toFixed(2)} €`);       // toFixed(2) : 2 décimales → 33.75
console.log(`Livraison : ${livraison.toFixed(2)} €`);
console.log(`À payer : ${(total + livraison).toFixed(2)} €`);

Exercice 1 — Ta carte d'identité

Ce qu'on attend de toi : 4 variables (prénom, ville, âge, estEtudiant) avec le bon mot-clé et le bon type, puis une phrase affichée dans la console avec un template string :

Je m'appelle Hassnein, j'habite à Bruxelles, j'ai 19 ans. Étudiant : true

Puis augmente l'âge de 1 et affiche-le à nouveau.

Comment vérifier : la console affiche la phrase, puis 20, sans erreur rouge.

Indice

Seul l'âge change : c'est le seul en let. Les accents graves `…` et ${…} pour la phrase.

Correction (ouvre-la après avoir essayé) 
const prenom = "Hassnein";     // texte → string, ne change pas → const
const ville = "Bruxelles";
let age = 19;                  // nombre, va changer → let
const estEtudiant = true;      // oui/non → boolean

console.log(`Je m'appelle ${prenom}, j'habite à ${ville}, j'ai ${age} ans. Étudiant : ${estEtudiant}`);

age++;                         // age vaut maintenant 20
console.log(age);

Exercice 2 — Le calculateur de TVA belge

Ce qu'on attend de toi : à partir d'un prixHT et d'une categorie ("standard", "restaurant" ou "alimentation"), calculer le prix TTC avec le bon taux belge et afficher :

Prix HT : 100.00 € — TVA (21 %) : 21.00 € — Prix TTC : 121.00 €

Taux : standard 21 %, restaurant 12 %, alimentation 6 %. Teste les 3 catégories en changeant la variable.

Comment vérifier : 100 € en restaurant donne 112.00 € ; en alimentation 106.00 €.

Indice 1

Une variable let taux; sans valeur, puis un if / else if / else qui lui donne 21, 12 ou 6.

Indice 2

TVA = prixHT × taux / 100. Pour 2 décimales : .toFixed(2).

Correction (ouvre-la après avoir essayé) 
const prixHT = 100;
const categorie = "restaurant";

let taux;                              // pas encore de valeur : elle dépend de la catégorie
if (categorie === "restaurant") {
  taux = 12;
} else if (categorie === "alimentation") {
  taux = 6;
} else {
  taux = 21;                           // tout le reste : taux standard
}

const tva = prixHT * taux / 100;
const prixTTC = prixHT + tva;

console.log(`Prix HT : ${prixHT.toFixed(2)} € — TVA (${taux} %) : ${tva.toFixed(2)} € — Prix TTC : ${prixTTC.toFixed(2)} €`);

Pourquoi else pour le standard ? C'est le cas « par défaut » : toute catégorie inconnue reçoit 21 %.

Exercice 3 — Les mentions

Ce qu'on attend de toi : une variable note (sur 20). Afficher la mention : 18+ « La plus grande distinction », 16+ « Grande distinction », 14+ « Distinction », 12+ « Satisfaction », 10+ « Réussi », sinon « Échec ». Si la note est négative ou au-dessus de 20 : « Note invalide ».

Comment vérifier : teste 20, 17, 10, 9, -3 et 25.

Indice

Teste d'abord le cas invalide, avec ||. Ensuite, du plus haut au plus bas.

Correction (ouvre-la après avoir essayé) 
const note = 17;

if (note < 0 || note > 20) {          // OU : il suffit qu'une des deux soit vraie
  console.log("Note invalide");
} else if (note >= 18) {
  console.log("La plus grande distinction");
} else if (note >= 16) {
  console.log("Grande distinction");    // ← 17
} else if (note >= 14) {
  console.log("Distinction");
} else if (note >= 12) {
  console.log("Satisfaction");
} else if (note >= 10) {
  console.log("Réussi");
} else {
  console.log("Échec");
}

Exercice 4 — Boucles : la table et le « Bruxelles-Liège »

Ce qu'on attend de toi :

  1. Afficher la table de multiplication d'un nombre choisi, de 1 à 10 : 7 x 1 = 7 … 7 x 10 = 70.
  2. Pour les nombres de 1 à 20 : afficher « Bruxelles » s'il est divisible par 3, « Liège » s'il est divisible par 5, « Bruxelles-Liège » s'il est divisible par les deux, sinon le nombre lui-même. (C'est un classique des entretiens d'embauche, le « FizzBuzz » !)

Comment vérifier : 3 → Bruxelles, 5 → Liège, 15 → Bruxelles-Liège, 7 → 7.

Indice

Divisible par 3 = i % 3 === 0. Pour le cas « les deux », pense à l'ordre des conditions (notion 5) : teste-le en premier.

Correction (ouvre-la après avoir essayé) 
// 1. Table de multiplication
const nombre = 7;
for (let i = 1; i <= 10; i++) {
  console.log(`${nombre} x ${i} = ${nombre * i}`);
}

// 2. Bruxelles-Liège
for (let i = 1; i <= 20; i++) {
  if (i % 3 === 0 && i % 5 === 0) {   // les deux EN PREMIER, sinon 15 afficherait "Bruxelles"
    console.log("Bruxelles-Liège");
  } else if (i % 3 === 0) {
    console.log("Bruxelles");
  } else if (i % 5 === 0) {
    console.log("Liège");
  } else {
    console.log(i);
  }
}

Exercice 5 — Lire une erreur

Ce qu'on attend de toi : copier ce code, lire chaque erreur rouge dans la console, et corriger les 3 bugs un par un.

const panier = 25;
const livraison = 5
if (panier = 30) {
  livraison = 0;
}
console.log(`Total : ${panier + livraisonn}`);
Indice

Comparaison ou rangement ? const qui change ? Faute de frappe dans un nom ?

Correction (ouvre-la après avoir essayé) 
const panier = 25;
let livraison = 5;                // 1. let : la valeur peut changer (et on ajoute le ;)
if (panier >= 30) {               // 2. on COMPARE (>=), on ne range pas (=)
  livraison = 0;
}
console.log(`Total : ${panier + livraison}`);   // 3. "livraisonn" → "livraison"

La méthode : lis le message, va à la ligne indiquée (script.js:3), corrige une erreur, rafraîchis, recommence.

Un message de bienvenue dans la console

Ce qu'on attend de toi : à la fin de site/js/main.js, un message dans la console qui dépend de l'heure : « Bonjour » avant 12 h, « Bon après-midi » avant 18 h, sinon « Bonsoir », suivi de « — bonne session de formation ! ».

Indice

new Date().getHours() donne l'heure actuelle (un nombre de 0 à 23).

Correction (ouvre-la après avoir essayé) 
// Ma contribution (leçon 1.6) : un message selon l'heure
const heure = new Date().getHours();
let salutation;
if (heure < 12) {
  salutation = "Bonjour";
} else if (heure < 18) {
  salutation = "Bon après-midi";
} else {
  salutation = "Bonsoir";
}
console.log(`${salutation} — bonne session de formation !`);

Questions pour vérifier que tu as compris

1. const ou let pour le total d'un panier qui augmente à chaque article ajouté ?

Réponse

let : sa valeur change. Tout ce qui ne change pas : const.

2. Que donne "10" + 5 ? Et Number("10") + 5 ?

Réponse

"105" (texte collé), puis 15 (vrai calcul).

3. Quelle est la différence entre = et === ?

Réponse

= range une valeur dans une variable ; === compare deux valeurs et donne true ou false.

4. Combien de fois tourne for (let i = 0; i < 3; i++) ?

Réponse

3 fois : i vaut 0, 1, puis 2. À 3, la condition i < 3 est fausse.

Checklist

  • Je relie un fichier JS et j'utilise la console (log et erreurs).
  • Je choisis entre const et let, et je nomme en camelCase.
  • Je connais les types string, number, boolean, et les template strings.
  • Je calcule et je compare avec ===, &&, ||.
  • J'écris des conditions if / else if / else dans le bon ordre.
  • J'écris des boucles for et while sans boucle infinie.
  • Je lis un message d'erreur et je vais à la bonne ligne.
