Projet 1.9 · environ 4 h

Projet : le suivi de progression

Objectif : construire ta première vraie fonctionnalité du site. Sur la page Parcours, chaque leçon reçoit une case « terminé » qui reste cochée après rechargement, et une barre de progression affiche ton avancement en pourcentage. Tu vas aussi apprendre la méthode pour mener un projet : spécifier, découper, construire étape par étape.

Notion 1 — Mener un projet : spécifier, puis découper

La spécification (ce que la fonctionnalité doit faire)

  1. Sur parcours.html, chaque ligne de leçon a une case à cocher, à gauche du numéro.
  2. Cocher une case marque la leçon comme terminée : la ligne devient grisée.
  3. En haut de la page, un texte « 12 / 75 leçons terminées (16 %) » et une barre qui se remplit.
  4. Tout reste en mémoire après un rechargement ou une fermeture du navigateur.

Le découpage en étapes testables

ÉtapeRésultat visible
1. La zone de progression (HTML + CSS)une barre vide et un texte
2. Les cases à cocher (JS)une case devant chaque leçon
3. Mémoriser (localStorage)les cases restent cochées après F5
4. Calculer et afficher la progressionla barre bouge quand on coche
5. Le style « terminé »les lignes cochées sont grisées

Pourquoi découper ? Si tu écris tout d'un coup et que ça ne marche pas, tu ne sais pas où chercher. Une étape à la fois, testée, commitée : si quelque chose casse, c'est forcément la dernière étape. C'est aussi comme ça qu'on fait travailler une IA efficacement (Phase 4).

Notion 2 — Les nouveaux outils de ce projet

La case à cocher

<input type="checkbox">                    <!-- en HTML -->

const caseACocher = document.createElement("input");   // en JavaScript
caseACocher.type = "checkbox";
caseACocher.checked = true;                            // cochée (true) ou non (false)
caseACocher.addEventListener("change", () => {         // "change" : cochée ou décochée
  console.log(caseACocher.checked);
});

Insérer au début : prepend

appendChild ajoute à la fin d'un élément ; element.prepend(…) ajoute au début (ici : la case avant le numéro).

Une exception à la règle « le style dans le CSS »

La largeur de la barre dépend d'un calcul (17 %, 42 %…) : impossible de prévoir une classe pour chaque valeur. Dans ce cas précis, JavaScript change le style directement : barre.style.width = "17%";. Toutes les autres propriétés (couleur, hauteur, arrondi) restent dans le CSS.

Identifier chaque leçon

Pour mémoriser quelles leçons sont terminées, il faut un identifiant unique par leçon. Il existe déjà : le texte de <span class="numero"> (« 0.1 », « 1.9 »…). On mémorise un tableau de numéros : ["0.1", "0.2", "1.1"].

Le projet, étape par étape

Fichiers : tu travailles dans site/parcours.html, site/css/style.css et un nouveau fichier site/js/progression.js, relié seulement à parcours.html (juste après la ligne main.js). Fais un commit après chaque étape réussie.

Étape 2 — Une case devant chaque leçon

Ce qu'on attend de toi : dans progression.js, pour chaque li des listes de leçons, créer une case à cocher et l'insérer au début de la ligne. Chaque case a un aria-label du type « Leçon 1.9 terminée » (pour les lecteurs d'écran).

Comment vérifier : les 75 lignes ont une case ; F12 › Console : aucune erreur.

Indice

document.querySelectorAll(".liste-lecons li"), puis pour chaque ligne : ligne.querySelector(".numero").textContent donne le numéro.

Correction (ouvre-la après avoir essayé) 
// =========================================================
// Projet 1.9 — Suivi de progression (page Parcours)
// =========================================================

// 1. Toutes les lignes de leçons de la page
const lignes = document.querySelectorAll(".liste-lecons li");

// 2. Une case à cocher au début de chaque ligne
lignes.forEach((ligne) => {
  const numero = ligne.querySelector(".numero").textContent;   // ex. "1.9"

  const caseACocher = document.createElement("input");
  caseACocher.type = "checkbox";
  caseACocher.setAttribute("aria-label", `Leçon ${numero} terminée`);

  ligne.prepend(caseACocher);
});

Attention : n'appelle pas ta variable case, c'est un mot réservé de JavaScript.

Étape 3 — Mémoriser les cases cochées

Ce qu'on attend de toi : un tableau terminees (les numéros des leçons terminées), relu depuis localStorage (clé "lecons-terminees") au chargement. Chaque case est cochée si son numéro est dans le tableau. Quand on coche ou décoche, le tableau est mis à jour et sauvegardé.

Comment vérifier : coche 3 cases, recharge : elles sont toujours cochées. F12 › Application › Local Storage montre ["0.1","0.2","0.3"].

Indice 1

Au chargement : JSON.parse(localStorage.getItem(…)) || [] (leçon 1.8). Pour cocher : caseACocher.checked = terminees.includes(numero).

Indice 2

Décocher = retirer le numéro du tableau : terminees = terminees.filter((n) => n !== numero) (leçon 1.7). Il faut donc un let.

Correction (ouvre-la après avoir essayé) 
// La donnée : les numéros des leçons terminées, relus depuis la mémoire du navigateur
let terminees = JSON.parse(localStorage.getItem("lecons-terminees")) || [];

function sauvegarder() {
  localStorage.setItem("lecons-terminees", JSON.stringify(terminees));
}

lignes.forEach((ligne) => {
  const numero = ligne.querySelector(".numero").textContent;

  const caseACocher = document.createElement("input");
  caseACocher.type = "checkbox";
  caseACocher.setAttribute("aria-label", `Leçon ${numero} terminée`);
  caseACocher.checked = terminees.includes(numero);      // cochée si déjà terminée

  caseACocher.addEventListener("change", () => {
    if (caseACocher.checked) {
      terminees.push(numero);                            // on ajoute
    } else {
      terminees = terminees.filter((n) => n !== numero); // on retire
    }
    sauvegarder();
  });

  ligne.prepend(caseACocher);
});

Étape 4 — Calculer et afficher la progression

Ce qu'on attend de toi : une fonction afficherProgression() qui écrit « 3 / 75 leçons terminées (4 %) » et règle la largeur de la barre. Elle est appelée au chargement et à chaque changement de case.

Comment vérifier : la barre avance quand tu coches, recule quand tu décoches, et garde sa valeur après F5.

Indice

Total = lignes.length. Pourcentage = Math.round(terminees.length / total * 100). Largeur : barre.style.width = `${pourcentage}%`.

Correction (ouvre-la après avoir essayé) 
const texteProgression = document.querySelector("#texte-progression");
const barreRemplie = document.querySelector("#barre-remplie");

function afficherProgression() {
  const total = lignes.length;
  const nombre = terminees.length;
  const pourcentage = Math.round(nombre / total * 100);

  texteProgression.textContent = `${nombre} / ${total} leçons terminées (${pourcentage} %)`;
  barreRemplie.style.width = `${pourcentage}%`;          // la seule valeur de style calculée en JS
}

// … dans l'écouteur "change", après sauvegarder() :
//     afficherProgression();

afficherProgression();                                   // au chargement de la page

Étape 5 — Le style « terminé »

Ce qu'on attend de toi : une ligne cochée reçoit la classe terminee : le texte de la leçon devient grisé et barré. Les cases ont la couleur d'accent.

Correction complète du fichier progression.js (ouvre-la après avoir essayé) 
// =========================================================
// Projet 1.9 — Suivi de progression (page Parcours)
// Données : un tableau de numéros de leçons terminées, dans localStorage.
// =========================================================

const lignes = document.querySelectorAll(".liste-lecons li");
const texteProgression = document.querySelector("#texte-progression");
const barreRemplie = document.querySelector("#barre-remplie");

let terminees = JSON.parse(localStorage.getItem("lecons-terminees")) || [];

function sauvegarder() {
  localStorage.setItem("lecons-terminees", JSON.stringify(terminees));
}

function afficherProgression() {
  const total = lignes.length;
  const nombre = terminees.length;
  const pourcentage = Math.round(nombre / total * 100);
  texteProgression.textContent = `${nombre} / ${total} leçons terminées (${pourcentage} %)`;
  barreRemplie.style.width = `${pourcentage}%`;
}

lignes.forEach((ligne) => {
  const numero = ligne.querySelector(".numero").textContent;

  const caseACocher = document.createElement("input");
  caseACocher.type = "checkbox";
  caseACocher.setAttribute("aria-label", `Leçon ${numero} terminée`);
  caseACocher.checked = terminees.includes(numero);
  ligne.classList.toggle("terminee", caseACocher.checked);

  caseACocher.addEventListener("change", () => {
    if (caseACocher.checked) {
      terminees.push(numero);
    } else {
      terminees = terminees.filter((n) => n !== numero);
    }
    ligne.classList.toggle("terminee", caseACocher.checked);
    sauvegarder();
    afficherProgression();
  });

  ligne.prepend(caseACocher);
});

afficherProgression();

Questions pour vérifier que tu as compris

1. Pourquoi mémoriser des numéros ("1.9") plutôt que la position de la ligne (la 15e) ?

Réponse

Si on ajoute ou déplace une leçon dans le parcours, les positions changent et la mémoire cocherait les mauvaises cases. Un identifiant stable ne change pas.

2. Pourquoi afficherProgression() est-elle appelée à deux endroits ?

Réponse

Au chargement (pour afficher l'état mémorisé) et à chaque changement (pour mettre à jour). Même schéma qu'en 1.8 : donnée → affichage.
