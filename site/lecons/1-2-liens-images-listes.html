Leçon 1.2 · environ 2 h 30

HTML : textes, liens, images et listes

Objectif : mettre du texte en valeur, relier des pages entre elles et vers d'autres sites, afficher des images accessibles et organiser l'information en listes.

Notion 1 — Mettre du texte en valeur : <strong>, <em>, <br>

BaliseSensAffichage par défautQuand l'utiliser
<strong>C'est importantgrasUn mot clé, un avertissement
<em>On insiste en lisantitaliqueUne nuance, un mot étranger, un titre d'œuvre
<br>Retour à la ligne forcé—Seulement dans une adresse ou un poème. Pas pour espacer des paragraphes !
<p>La livraison est <strong>gratuite</strong> dès 30 €, <em>uniquement</em> à Bruxelles.</p>
<p>Rue Neuve 12<br>1000 Bruxelles</p>

Erreurs fréquentes

  • Utiliser <strong> juste pour avoir du gras « joli » : le gras décoratif, c'est le rôle du CSS.
  • Empiler des <br><br><br> pour faire de l'espace : utilise des <p> séparés, et le CSS pour l'espacement.

Notion 2 — Les liens : <a href="…">

C'est quoi ?

Un lien (anchor, ancre) emmène vers une autre page, un autre site, une adresse email ou un endroit de la même page. L'attribut href dit où aller ; le contenu de la balise est le texte cliquable.

Comment l'écrire : les 5 types de liens

<!-- 1. Vers une page de TON site : chemin relatif (comme en leçon 0.1) -->
<a href="parcours.html">Voir le parcours</a>
<a href="lecons/1-1-html.html">Leçon 1.1</a>       <!-- descendre dans un dossier -->
<a href="../index.html">Accueil</a>              <!-- remonter d'un dossier avec .. -->

<!-- 2. Vers un autre site : adresse complète, avec https:// -->
<a href="https://github.com">GitHub</a>

<!-- 3. Dans un nouvel onglet : target + rel (sécurité) -->
<a href="https://github.com" target="_blank" rel="noopener noreferrer">GitHub</a>

<!-- 4. Vers un email -->
<a href="mailto:contact@exemple.be">M'écrire</a>

<!-- 5. Vers un endroit de la même page : # + l'id de l'élément -->
<a href="#horaires">Voir les horaires</a>
<section id="horaires"> … </section>

Quand ouvrir dans un nouvel onglet ?

  • ✅ Pour un lien vers un autre site, quand tu veux que le visiteur garde ta page ouverte.
  • ❌ Pas pour les pages de ton propre site : le visiteur s'attend à rester dans le même onglet.
  • Toujours avec rel="noopener noreferrer" : la page ouverte ne peut pas prendre le contrôle de la tienne.

Un bon texte de lien

Le texte doit dire où mène le lien, même lu tout seul. Les lecteurs d'écran listent les liens, et Google lit ce texte (SEO).

❌ Pour le parcours, <a href="parcours.html">cliquez ici</a>
✅ <a href="parcours.html">Voir tout le parcours</a>

Erreurs fréquentes

  • href="github.com" sans https:// : le navigateur cherche un fichier nommé « github.com » dans ton dossier → page introuvable.
  • Oublier ../ depuis un sous-dossier : depuis lecons/, href="index.html" cherche lecons/index.html, qui n'existe pas.
  • Majuscules : Parcours.html ≠ parcours.html une fois en ligne (leçon 1.11). Écris tout en minuscules.

Notion 3 — Les images : <img>

Comment l'écrire

<img src="images/pizza-margherita.jpg" alt="Pizza margherita sortant du four à bois" width="600" height="400">
<!--  ↑ src : le chemin du fichier image (relatif, comme un lien)
       ↑ alt : la description de l'image, lue si elle ne s'affiche pas ou par un lecteur d'écran
       ↑ width / height : les dimensions en pixels, pour réserver la place pendant le chargement
     <img> est une balise orpheline : pas de </img> -->

Bien écrire le alt

  • Décris ce que l'image apporte : « Graphique : les ventes doublent en 2025 », pas « image » ou « photo ».
  • Image purement décorative (un trait, un fond) : alt="" (vide, mais présent), pour que les lecteurs d'écran l'ignorent.
  • Le alt est obligatoire : accessibilité et SEO (Google ne « voit » pas les images, il lit le alt).

Quel format d'image ?

FormatPour…
.jpgles photos
.pngles captures d'écran, les images avec transparence
.svgles logos et icônes (net à toutes les tailles)
.webples photos du web moderne (plus léger que jpg)

Où ranger les images ?

Dans un dossier images/, à côté de ta page. Noms en minuscules, avec des tirets, sans espace ni accent : photo-profil.jpg, pas Photo de Profil (1).JPG.

Erreurs fréquentes

  • Image cassée (une icône 🖼️ s'affiche) : le chemin est faux, ou le nom ne correspond pas exactement (majuscule, extension .jpeg au lieu de .jpg). Vérifie avec F12 › onglet Console.
  • Une photo de 5 Mo directement du téléphone : la page devient lente. Réduis-la (par exemple sur squoosh.app) sous 300 Ko.

Notion 4 — Les listes : <ul>, <ol>, <li>

Comment l'écrire

<!-- ul = liste à puces (unordered list) : l'ordre n'a pas d'importance -->
<ul>
  <li>Tomates</li>          <!-- li = un élément de liste (list item) -->
  <li>Mozzarella</li>
</ul>

<!-- ol = liste numérotée (ordered list) : l'ordre compte -->
<ol>
  <li>Étaler la pâte</li>
  <li>Ajouter la sauce</li>
  <li>Cuire 90 secondes</li>
</ol>

<!-- Liste dans une liste : le <ul> va DANS le <li> -->
<ul>
  <li>Pizzas
    <ul>
      <li>Margherita</li>
      <li>Quattro formaggi</li>
    </ul>
  </li>
</ul>

Quand utiliser laquelle ?

  • <ol> : des étapes, un classement, une recette — si on change l'ordre, le sens change.
  • <ul> : des ingrédients, des compétences, des liens de menu — l'ordre est libre.
  • Un menu de navigation est souvent une <ul> de liens dans un <nav>.

Erreurs fréquentes

  • Du texte directement dans <ul> : seuls des <li> peuvent être ses enfants directs.
  • Taper des « - » ou « 1. » à la main dans des <p> : c'est une liste, utilise la balise.

Exemple complet : tout combiner

<main>
  <section id="carte">
    <h2>Notre carte</h2>
    <img src="images/margherita.jpg" alt="Pizza margherita avec basilic frais" width="600" height="400">
    <ul>
      <li><strong>Margherita</strong> — 11 €</li>
      <li><strong>Regina</strong> — 13 € <em>(notre préférée)</em></li>
    </ul>
  </section>

  <section>
    <h2>Commander en 3 étapes</h2>
    <ol>
      <li>Choisis ta pizza dans <a href="#carte">la carte</a>.</li>
      <li>Appelle-nous ou <a href="mailto:commande@mammamia.be">écris-nous</a>.</li>
      <li>Viens la chercher : <a href="https://www.openstreetmap.org" target="_blank" rel="noopener noreferrer">voir le plan</a>.</li>
    </ol>
  </section>
</main>

Exercices

Exercice 1 — Ma page de favoris

Ce qu'on attend de toi : exercices/module-1-2/favoris.html (squelette complet) avec :

  • un <h1> « Mes favoris » dans un <header> ;
  • une section « Mes sites utiles » : une <ul> de 3 liens externes qui s'ouvrent dans un nouvel onglet ;
  • une section « Mon top 3 des outils » : une <ol> de 3 outils, avec le nom en <strong> et une courte raison ;
  • un <footer> avec un lien email (mailto:).

Comment vérifier : chaque lien externe ouvre un nouvel onglet ; le top 3 est numéroté automatiquement ; le lien email ouvre ta messagerie.

Indice

Un lien dans une liste = un <a> dans un <li>. Pour le nouvel onglet : target et rel (notion 2, type 3).

Exercice 2 — Ajouter ta photo

Ce qu'on attend de toi : une image affichée dans exercices/module-1-1/a-propos.html, sous ton <h1>, avec un alt descriptif. Le fichier image est dans exercices/module-1-1/images/, avec un nom sans espace.

  1. Choisis une image (ta photo, un logo, une capture d'écran) et copie-la dans exercices/module-1-1/images/.
  2. Renomme-la dans le terminal avec mv, par exemple en photo-profil.jpg.
  3. Ajoute la balise <img> dans le header, sous le <h1>.

Comment vérifier : l'image s'affiche ; si tu changes volontairement le src, c'est ton texte alt qui apparaît.

Indice

Le chemin part de l'endroit où se trouve la page : a-propos.html et le dossier images sont côte à côte, donc src="images/…".

Correction (ouvre-la après avoir essayé) 
mkdir exercices/module-1-1/images
mv "exercices/module-1-1/images/Photo de profil.JPG" exercices/module-1-1/images/photo-profil.jpg
<header>
  <h1>Hassnein Khawary</h1>
  <img src="images/photo-profil.jpg" alt="Portrait de Hassnein souriant" width="200" height="200">
</header>

Les guillemets autour du premier nom sont nécessaires à cause des espaces (leçon 0.1).

Contraintes : liens externes dans un nouvel onglet et sécurisés, textes de liens descriptifs. Critère : tous les liens fonctionnent. »

Ce qu'il faut retenir

L'IA écrit vite un code correct, mais les faits (adresses, prix, noms) doivent toujours être vérifiés. Relire = cliquer, tester, comparer avec ce que tu as appris.

Questions pour vérifier que tu as compris

1. Une recette de cuisine : ul ou ol pour les ingrédients ? Et pour les étapes ?

Réponse

Ingrédients : ul (l'ordre ne compte pas). Étapes : ol (l'ordre compte).

2. À quoi sert l'attribut alt ?

Réponse

Il décrit l'image pour ceux qui ne la voient pas : lecteurs d'écran, image qui ne charge pas, et Google.

3. Depuis site/lecons/1-2.html, quel href pour aller à site/portfolio.html ?

Réponse

../portfolio.html : on remonte de lecons/ vers site/.
