Leçon 1.3 · environ 3 h

CSS : sélecteurs, couleurs et box model

Objectif : relier une feuille de style à une page, cibler les bons éléments, choisir couleurs, tailles et polices, comprendre le box model et la cascade, et déboguer le style avec F12.

Notion 1 — Relier le CSS et lire une règle

Relier un fichier CSS

<head>
  …
  <link rel="stylesheet" href="style.css">   <!-- chemin relatif vers le fichier, comme un lien -->
</head>

Toujours un fichier .css séparé : un seul fichier stylise toutes les pages, et le HTML reste lisible. (Il existe aussi l'attribut style="…" sur une balise : à éviter, sauf pour un test rapide.)

Anatomie d'une règle

h1 {                     /* SÉLECTEUR : qui on stylise */
  color: #e11d48;        /* PROPRIÉTÉ : VALEUR ;  ← le point-virgule termine chaque déclaration */
  font-size: 2.5rem;
}                        /* les accolades entourent les déclarations */

Erreurs fréquentes

  • Oublier un ; : la déclaration suivante est ignorée sans message d'erreur.
  • Un mauvais chemin dans href : la page s'affiche sans aucun style. Vérifie avec F12 › Console (erreur 404).
  • Écrire en français : couleur: rouge ne marche pas. Le CSS est en anglais : color: red.

Notion 2 — Les sélecteurs : cibler les bons éléments

SélecteurCibleQuand l'utiliser
ptous les <p>Le style de base d'une balise
.cartetous les éléments avec class="carte"Le plus courant. Un style réutilisable
#horairesl'élément avec id="horaires"Rarement en CSS (l'id est unique, et trop « fort »). Garde-le pour les ancres et le JavaScript
.carte h3les <h3> à l'intérieur d'une .carteStyliser selon l'endroit
h1, h2les h1 et les h2Le même style pour plusieurs
a:hoverun lien survolé par la sourisLes effets d'interaction
<!-- HTML : on donne des classes -->
<p class="intro important">Bienvenue</p>      <!-- plusieurs classes : séparées par un espace -->

/* CSS : le point = "classe" */
.intro { font-size: 1.2rem; }
.important { font-weight: bold; }

Bien nommer une classe

Nomme selon le rôle, pas l'apparence : .prix-promo plutôt que .texte-rouge (si la promo devient verte, le nom resterait faux).

Notion 3 — Couleurs, unités et textes

Les couleurs

ÉcritureExempleQuand
Hexadécimal#e11d48Le plus courant (copié depuis un outil de design)

color = couleur du texte ; background = couleur du fond. Vérifie toujours le contraste : texte gris clair sur fond blanc = illisible.

Les unités

UnitéSensPour…
pxpixels, fixebordures, petites ombres
remmultiple de la taille de texte de base (1rem ≈ 16px)tailles de texte et espacements (respecte les réglages de l'utilisateur)

Le texte

body {
  font-family: "Segoe UI", system-ui, sans-serif;  /* liste de secours : si la 1re police manque, la suivante */
  font-size: 1rem;
  line-height: 1.6;          /* hauteur de ligne : 1.5 à 1.7 = confortable à lire */
}
h1 { font-weight: 700; }     /* épaisseur : 400 normal, 700 gras */
.centre { text-align: center; }
a { text-decoration: none; } /* enlève le soulignement */

Notion 4 — Le box model : chaque élément est une boîte

┌──────────── margin (espace EXTÉRIEUR, transparent) ───────────┐
│ ┌────────── border (la bordure) ─────────────────────────────┐ │
│ │ ┌──────── padding (espace INTÉRIEUR, prend le fond) ─────┐ │ │
│ │ │              content (le contenu : texte, image)       │ │ │
│ │ └────────────────────────────────────────────────────────┘ │ │
│ └────────────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────────┘
.carte {
  padding: 20px;                 /* 20px de chaque côté, à l'intérieur */
  border: 1px solid #e3e0d8;     /* épaisseur, style, couleur */
  border-radius: 14px;           /* coins arrondis */
  margin: 0 0 16px;              /* haut 0, côtés 0, bas 16px */
}
* { box-sizing: border-box; }    /* la largeur INCLUT padding et bordure : bien plus simple */

Padding ou margin ?

  • padding : pour éloigner le contenu de sa propre bordure (le texte d'un bouton respire).
  • margin : pour éloigner la boîte de ses voisines.

Les raccourcis : margin: 10px (4 côtés) · margin: 10px 20px (haut/bas, gauche/droite) · margin: 0 auto (centre horizontalement un bloc qui a une largeur).

Notion 5 — La cascade : quand deux règles se disputent

Le C de CSS veut dire Cascading. Quand plusieurs règles visent le même élément :

  1. La plus spécifique gagne : #id > .classe > balise.
  2. À égalité, la dernière écrite gagne.
  3. Certaines propriétés (couleur, police) s'héritent : un color sur body s'applique à tout le texte.

Tu l'as vécu en leçon 0.4 : --accent redéfini plus bas, dans le bloc du mode sombre, gagnait sur ta modification.

Déboguer avec F12

F12 › Elements, clique sur un élément : le panneau Styles montre toutes les règles qui s'appliquent. Les déclarations barrées ont perdu la bataille de la cascade. Tu peux même changer une valeur en direct pour tester (sans modifier ton fichier).

  • !important force une règle à gagner. Ne l'utilise pas pour « réparer » : cherche plutôt pourquoi la règle perd.

Exercices

Exercice 1 — Habiller ta page À propos

Ce qu'on attend de toi : un fichier exercices/module-1-1/style.css relié à ton a-propos.html, qui donne :

  • une police sans serif et une hauteur de ligne de 1.6 sur body, une couleur de fond douce ;
  • un h1 coloré ;
  • chaque section en « carte » : fond blanc, padding, bordure arrondie, marge en bas ;
  • un footer au texte centré et plus petit.

Comment vérifier : chaque section apparaît comme une carte séparée ; avec F12, tu retrouves tes règles dans le panneau Styles.

Indice

4 règles : body, h1, section, footer. N'oublie pas le <link> dans le <head>.

Correction (ouvre-la après avoir essayé) 
<!-- Dans le <head> de a-propos.html -->
<link rel="stylesheet" href="style.css">
body {
  font-family: "Segoe UI", system-ui, sans-serif;
  line-height: 1.6;
  background: #f7f5f0;
  color: #1d1d1f;
  margin: 0;
  padding: 24px;
}

h1 { color: #e11d48; }

section {
  background: #ffffff;
  padding: 20px;
  border: 1px solid #e3e0d8;
  border-radius: 14px;
  margin-bottom: 16px;
}

footer {
  text-align: center;
  font-size: 0.9rem;
  color: #5f6368;
}

Exercice 2 — Classes et survol

Ce qu'on attend de toi : dans favoris.html (leçon 1.2), une classe lien-externe sur les 3 liens externes, stylisée sans soulignement, en gras, qui change de couleur et se souligne au survol.

Correction (ouvre-la après avoir essayé) 
<a class="lien-externe" href="https://github.com" target="_blank" rel="noopener noreferrer">GitHub</a>
.lien-externe {
  font-weight: 700;
  text-decoration: none;
  color: #4f46e5;
}
.lien-externe:hover {
  color: #e11d48;
  text-decoration: underline;
}

Exercice 3 — Enquête sur la cascade

Ce qu'on attend de toi : prédire la couleur du texte, puis vérifier.

<p class="note" id="info">Quelle couleur ?</p>

#info { color: green; }
p { color: blue; }
.note { color: red; }
Réponse

Vert : #info est le plus spécifique (id > classe > balise), même s'il est écrit en premier.

🔧 Ajout au site

Ta propre couleur d'accent et une classe « mise en avant »

Ce qu'on attend de toi : dans site/css/style.css, à la fin, une classe .mise-en-avant (fond var(--accent-doux), padding, coins arrondis) appliquée à ta section « Pourquoi je me forme » de l'accueil.

Correction (ouvre-la après avoir essayé) 
/* Ma contribution (leçon 1.3) */
.mise-en-avant {
  background: var(--accent-doux);
  padding: 20px 24px;
  border-radius: var(--rayon);
}
<section class="mise-en-avant">
  <h2>Pourquoi je me forme</h2>
  …

On réutilise les variables du site (var(--…)) : la classe suit automatiquement le mode sombre.

Questions pour vérifier que tu as compris

1. Padding ou margin pour éloigner deux cartes l'une de l'autre ?

Réponse

margin : c'est l'espace à l'extérieur de la boîte.

2. Tu as écrit une règle mais rien ne change. Cite 3 causes possibles.

Réponse

Fichier non enregistré ou page non rafraîchie ; <link> avec un mauvais chemin ; règle plus spécifique ailleurs (cascade) ; faute de frappe ou ; manquant. F12 › Styles pour trancher.

  • Je choisis couleurs, unités (rem) et polices.
  • Je sais la différence entre padding, border et margin.
  • Je comprends la cascade et je débogue avec F12 › Styles.
