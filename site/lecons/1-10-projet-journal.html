Projet 1.10 · environ 5 h

Projet : le journal d'apprentissage

Objectif : sur la page Journal, un formulaire pour écrire une entrée (date, leçon, ce que j'ai appris, ce qui était difficile), la liste des entrées de la plus récente à la plus ancienne, et un bouton pour supprimer. Tout reste en mémoire. Tu apprends les formulaires, la base de toutes les applications (inscription, commande, contact…).

Notion 1 — Les formulaires HTML

Comment l'écrire

<form id="formulaire-journal">
  <label for="date">Date</label>
  <input id="date" name="date" type="date" required>

  <label for="lecon">Leçon</label>
  <input id="lecon" name="lecon" type="text" placeholder="ex. 1.10" required>

  <label for="appris">Ce que j'ai appris</label>
  <textarea id="appris" name="appris" rows="4" required></textarea>

  <button type="submit">Enregistrer</button>
</form>
ÉlémentRôle
<form>regroupe les champs ; « Entrée » ou le bouton submit l'envoient
<label for="id">le nom du champ, relié par l'id. Obligatoire : accessibilité, et un clic sur le texte active le champ
<input type="…">un champ d'une ligne : text, email, date, number, password, checkbox…
<textarea>un champ de plusieurs lignes (avec une balise fermante)
requiredle navigateur refuse l'envoi si le champ est vide, et affiche un message
placeholderun exemple grisé dans le champ (pas un remplaçant du label !)
<button type="submit">envoie le formulaire

Quel type de champ ?

Le bon type donne le bon clavier sur téléphone et une vérification gratuite : email vérifie la présence d'un @, date affiche un calendrier, number un pavé numérique.

Notion 2 — Intercepter l'envoi : submit et preventDefault

Par défaut, envoyer un formulaire recharge la page (il est prévu pour envoyer les données à un serveur). Ici, on veut garder la main en JavaScript :

const formulaire = document.querySelector("#formulaire-journal");

formulaire.addEventListener("submit", (evenement) => {
  evenement.preventDefault();               // ① empêche le rechargement de la page

  const date = formulaire.date.value;       // ② lire les champs par leur attribut name
  const lecon = formulaire.lecon.value.trim();

  console.log(date, lecon);                 // ③ faire quelque chose avec
  formulaire.reset();                       // ④ vider tous les champs
});

Pourquoi submit sur le formulaire et pas click sur le bouton ?

submit se déclenche aussi avec la touche Entrée, et seulement si les champs required sont remplis. C'est plus complet et plus accessible.

  • Oublier preventDefault() : la page se recharge et tout ce que tu as fait disparaît en une fraction de seconde.

Notion 3 — Des entrées avec un identifiant, et des dates lisibles

Un objet par entrée, avec un id

const entree = {

  date: "2026-10-26",
  lecon: "1.10",
  appris: "Les formulaires et preventDefault",
  difficile: "Comprendre le name des champs"

Pourquoi un id ? Pour supprimer cette entrée précisément, même si deux entrées ont la même date et la même leçon : entrees = entrees.filter((e) => e.id !== idASupprimer).

// → "lundi 26 octobre 2026"

Étape 2 — Enregistrer une entrée

Ce qu'on attend de toi : dans journal.js, à l'envoi du formulaire : empêcher le rechargement, créer un objet entrée (avec id), l'ajouter au début d'un tableau entrees, sauvegarder dans localStorage (clé "journal"), vider le formulaire.

Comment vérifier : après un envoi, F12 › Application › Local Storage › journal contient ton entrée ; la page ne s'est pas rechargée.

Indice

Même structure qu'en 1.8 : la donnée relue avec JSON.parse(…) || [], une fonction sauvegarder().

Correction (ouvre-la après avoir essayé) 
// =========================================================
// Projet 1.10 — Journal d'apprentissage (page Journal)
// =========================================================

const formulaire = document.querySelector("#formulaire-journal");
const zoneEntrees = document.querySelector("#entrees");

let entrees = JSON.parse(localStorage.getItem("journal")) || [];

function sauvegarder() {
  localStorage.setItem("journal", JSON.stringify(entrees));
}

formulaire.addEventListener("submit", (evenement) => {
  evenement.preventDefault();

  const entree = {
    id: Date.now(),
    date: formulaire.date.value,
    lecon: formulaire.lecon.value.trim(),
    appris: formulaire.appris.value.trim(),
    difficile: formulaire.difficile.value.trim()
  };

  entrees.unshift(entree);      // la plus récente en premier
  sauvegarder();
  formulaire.reset();
});

Étape 3 — Afficher les entrées

Ce qu'on attend de toi : une fonction afficherEntrees() qui, pour chaque entrée, crée un <article class="carte"> avec : la date lisible et la leçon en titre (h3), « Appris : … », et « Difficile : … » seulement si ce champ est rempli. Si le journal est vide : « Aucune entrée pour l'instant. » Appelée au chargement et après chaque ajout.

Indice

Pour chaque partie : createElement + textContent (pas innerHTML : c'est du texte tapé par un utilisateur, leçon 1.8).

Correction (ouvre-la après avoir essayé) 
function formaterDate(dateTexte) {
  return new Date(dateTexte).toLocaleDateString("fr-BE", {
    weekday: "long", day: "numeric", month: "long", year: "numeric"
  });
}

function afficherEntrees() {
  zoneEntrees.innerHTML = "";              // on vide (pas de texte utilisateur ici : sans risque)

  if (entrees.length === 0) {
    const vide = document.createElement("p");
    vide.textContent = "Aucune entrée pour l'instant.";
    zoneEntrees.appendChild(vide);
    return;
  }

  for (const entree of entrees) {
    const article = document.createElement("article");
    article.className = "carte entree-journal";

    const titre = document.createElement("h3");
    titre.textContent = `${formaterDate(entree.date)} — Leçon ${entree.lecon}`;
    article.appendChild(titre);

    const appris = document.createElement("p");
    appris.textContent = `Appris : ${entree.appris}`;
    article.appendChild(appris);

    if (entree.difficile) {                // une chaîne vide "" compte comme faux
      const difficile = document.createElement("p");
      difficile.textContent = `Difficile : ${entree.difficile}`;
      article.appendChild(difficile);
    }

    zoneEntrees.appendChild(article);
  }
}

Questions pour vérifier que tu as compris

1. Que se passe-t-il sans preventDefault() ?

Réponse

La page se recharge à l'envoi du formulaire : le JavaScript n'a pas le temps d'afficher quoi que ce soit.

2. Pourquoi chaque entrée a-t-elle un id ?

Réponse

Pour identifier précisément l'entrée à supprimer ou modifier, même si deux entrées se ressemblent.

3. À quoi sert <label for="…"> ?

Réponse

Il relie le texte au champ : les lecteurs d'écran annoncent le nom du champ, et un clic sur le texte active le champ.

Checklist

  • J'écris un formulaire avec labels, types adaptés et required.
  • J'intercepte submit avec preventDefault() et je lis les champs.
  • Je stocke des objets avec un id, les plus récents en premier.
  • J'affiche une liste d'entrées en toute sécurité (textContent) et je supprime par id.
