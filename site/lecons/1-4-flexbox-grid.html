Leçon 1.4 · environ 3 h

CSS : flexbox et grid

Objectif : placer des éléments côte à côte, les aligner et les espacer avec flexbox, et construire des grilles de cartes avec grid. Ce sont les deux outils de mise en page du web moderne.

Notion 1 — Le flux normal : block et inline

Sans CSS de mise en page, les éléments suivent le « flux » :

TypeComportementExemples
blockprend toute la largeur, empile les uns sous les autresdiv, p, h1, section, ul
inlinereste dans la ligne de texte, ne prend que sa largeura, strong, em, span, img

<div> (bloc) et <span> (en ligne) sont des boîtes sans sens : on les utilise seulement pour la mise en page ou le style, quand aucune balise sémantique ne convient.

Pour mettre des blocs côte à côte, on change le display du parent : flex ou grid.

Notion 2 — Flexbox : aligner sur une ligne

C'est quoi ?

display: flex sur un parent range ses enfants directs sur une ligne (ou une colonne), et permet de les aligner et de les espacer.

Comment l'écrire

.menu {
  display: flex;                    /* les enfants se mettent en ligne */
  flex-direction: row;              /* row (ligne, par défaut) ou column (colonne) */
  justify-content: space-between;   /* répartition sur l'axe principal (horizontal en row) */
  align-items: center;              /* alignement sur l'autre axe (vertical en row) */
  gap: 16px;                        /* espace entre les enfants */
  flex-wrap: wrap;                  /* passe à la ligne si pas assez de place */
}
justify-contentEffet
flex-starttout au début
centertout au centre
space-betweenle 1er au début, le dernier à la fin, l'espace réparti entre
flex-endtout à la fin

Sur un enfant : flex: 1 le fait grandir pour prendre la place restante.

Quand l'utiliser ?

Pour une ligne ou une colonne d'éléments : un menu, un en-tête (logo à gauche, liens à droite), des boutons, une carte avec une icône et un texte. Va voir .entete .conteneur dans site/css/style.css : c'est un flexbox.

Centrer parfaitement

.centre-tout { display: flex; justify-content: center; align-items: center; min-height: 100vh; }
  • Mettre display: flex sur les enfants au lieu du parent.
  • Confondre les axes : en column, justify-content devient vertical.

Notion 3 — Grid : des lignes ET des colonnes

Comment l'écrire

.galerie {
  display: grid;
  grid-template-columns: 1fr 1fr 1fr;    /* 3 colonnes égales (fr = une part de l'espace libre) */
  gap: 18px;
}

/* La recette magique, sans media query : autant de colonnes que possible, de 260px minimum */
.grille {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(260px, 1fr));
  gap: 18px;
}

/* Un enfant qui prend 2 colonnes */
.vedette { grid-column: span 2; }

La classe .grille de ton site utilise exactement cette recette : c'est pour ça que les cartes passent de 3 colonnes sur ordinateur à 1 sur téléphone.

Flexbox ou grid ?

SituationOutil
Une rangée de liens, de boutonsflexbox
Aligner des éléments dans un en-têteflexbox
Une galerie, une grille de cartesgrid
La mise en page d'une page entière (colonnes)grid

Exercices

Exercice 1 — Une barre de navigation

Ce qu'on attend de toi : exercices/module-1-4/nav.html + nav.css : un header avec un logo texte à gauche et 3 liens à droite, alignés verticalement au centre, avec 20px entre les liens et un fond sombre.

Indice

Deux flexbox : le header (logo / nav, space-between) et le nav (les liens, gap).

Correction (ouvre-la après avoir essayé) 
<header class="barre">
  <a class="logo" href="#">MonSite</a>
  <nav class="liens">
    <a href="#">Accueil</a>
    <a href="#">Projets</a>
    <a href="#">Contact</a>
  </nav>
</header>
.barre {
  display: flex;
  justify-content: space-between;   /* logo à gauche, nav à droite */
  align-items: center;
  padding: 16px 24px;
  background: #1e1e2e;
}
.liens { display: flex; gap: 20px; }
.barre a { color: #ffffff; text-decoration: none; }
.logo { font-weight: 700; }

Questions pour vérifier que tu as compris

1. Sur quel élément met-on display: flex ?

Réponse

Sur le parent : ce sont ses enfants directs qui se rangent.

2. Que veut dire 1fr ?

Réponse

Une « fraction » de l'espace disponible : 1fr 2fr = la 2e colonne est deux fois plus large.
