Leçon 1.1 · environ 2 h

HTML : la structure d'une page

Objectif : comprendre comment une page web est construite, écrire ta première page à la main, et ajouter ta première vraie contribution à ce site.

Les 3 langages du web

Une page web, c'est comme une maison :

LangageDans la maisonSur une page
HTMLLes murs et les piècesLe contenu et la structure (titres, textes, images)
CSSLa peinture et la décoL'apparence (couleurs, tailles, mise en page)
JavaScriptL'électricitéLes actions (boutons, mémoire, interactions)

Cette leçon, c'est les murs.

Les balises

HTML entoure le contenu avec des balises qui disent ce qu'il est :

<h1>Je suis un grand titre</h1>
<p>Je suis un paragraphe.</p>
  • <h1> est la balise ouvrante, et </h1> la balise fermante (avec le /).
  • Une balise peut avoir des attributs, des informations en plus : <a href="parcours.html">Voir le parcours</a>. Ici, href dit où mène le lien.
  • Les balises s'emboîtent comme des poupées russes : on ferme toujours dans l'ordre inverse.

Le squelette de toute page

<!DOCTYPE html>                    <!-- « Ceci est une page HTML moderne » -->
<html lang="fr">                   <!-- la page entière, en français -->
<head>                             <!-- infos INVISIBLES pour le navigateur et Google -->
  <meta charset="UTF-8">           <!-- gère les accents : é, à, ç -->
  <meta name="viewport" content="width=device-width, initial-scale=1.0">  <!-- s'adapte au mobile -->
  <title>Mon titre</title>         <!-- le texte de l'onglet -->
</head>
<body>                             <!-- tout ce qui est VISIBLE -->
  <h1>Bonjour !</h1>
</body>
</html>

Raccourci VS Code : dans un fichier .html vide, tape ! puis appuie sur Tab. VS Code écrit tout le squelette pour toi. Mais écris-le à la main au moins une fois pour le comprendre !

Les balises de structure (sémantiques)

Elles découpent la page en zones qui ont un sens. Google et les lecteurs d'écran pour malvoyants les comprennent : c'est bon pour le SEO (Phase 5) et pour l'accessibilité.

BaliseRôle
<header>L'en-tête : logo, menu
<nav>Le menu de navigation
<main>Le contenu principal (un seul par page)
<section>Une partie du contenu, avec un thème
<article>Un contenu autonome (une leçon, un article de blog)
<footer>Le pied de page
<h1> à <h6>Les titres, du plus important au moins important. Un seul <h1> par page.

Observer une vraie page

Sur n'importe quelle page de ce site, appuie sur F12 (ou clic droit › Inspecter). Les outils de développement s'ouvrent : tu vois tout le HTML. Survole les lignes : la zone correspondante s'illumine sur la page.

Exercices

Exercice 1 — Ta première page, à la main

Crée exercices/module-1-1/a-propos.html, une page qui te présente. Elle doit contenir :

  • le squelette complet (écrit à la main, sans le raccourci !) ;
  • un <header> avec ton nom en <h1> ;
  • un <main> avec 2 <section> : « Mon parcours » et « Mes objectifs », chacune avec un <h2> et un paragraphe ;
  • un <footer> ;
  • au moins un commentaire.

Ouvre-la dans ton navigateur (double-clic sur le fichier) ou avec Live Preview.

Indice

Commence par le squelette, puis ajoute les zones une par une en vérifiant le résultat à chaque fois. Si quelque chose ne s'affiche pas, vérifie que chaque balise ouverte est bien fermée.

Exercice 2 — Le détective F12

Ouvre la page d'accueil de ce site, puis F12. Trouve dans le HTML : le <nav>, le <h1> et le lien du bouton « Continuer ». Vers quel fichier pointe ce lien ? Note tes réponses en commentaire en bas de a-propos.html.

🔧 Ajout au site (ta part du 50/50)

Ta première contribution : « Pourquoi je me forme »

Dans site/index.html, ajoute une nouvelle <section> juste avant </main>, avec :

  • un <h2> « Pourquoi je me forme » ;
  • un ou deux paragraphes, avec tes vraies raisons et ton objectif de business.

Le style s'applique tout seul : c'est la magie du CSS que tu découvriras en 1.3. Quand c'est fait, demande à Claude Code : « Relis ma section dans index.html. »

🤖 Refais-le avec l'IA

Tu as écrit ta page à la main : tu comprends maintenant ce que l'IA va produire. Place à ton premier exercice de construction avec l'IA.

Étape 1 — Le prompt vague

Dans Claude Code, écris seulement : « Fais-moi une page à propos. » Regarde ce que Claude te demande ou te propose. Que manquait-il à ta demande ?

Étape 2 — Le prompt précis

Écris maintenant une demande complète. Elle doit dire :

  • le contexte : qui tu es, à quoi sert la page ;
  • l'objectif : le fichier à créer (exercices/module-1-1/a-propos-ia.html) et ce qu'il doit contenir ;
  • les contraintes : HTML seulement, balises sémantiques, en français, des commentaires pour expliquer ;
  • le critère de réussite : par exemple « un seul <h1> et une page qui s'ouvre sans erreur ».
Exemple de structure (essaie d'abord sans !)

« Contexte : je suis débutant, leçon 1.1 de ma formation HTML. Objectif : crée … qui me présente avec un en-tête, deux sections (…) et un pied de page. Contraintes : … Critère de réussite : … »

Étape 3 — Compare et relis

  1. Ouvre côte à côte ta page (a-propos.html) et celle de l'IA (a-propos-ia.html).
  2. Trouve une chose que l'IA a mieux faite, et une chose que toi tu as mieux faite.
  3. Trouve une balise que l'IA a utilisée et que tu ne connais pas. Demande-lui de te l'expliquer.
  4. Copie ton meilleur prompt dans journal.md, sous un titre « Mes prompts ».

Demande enfin à Claude : « Note mon prompt de l'étape 2 sur 10 et propose une version améliorée. »

La règle d'or : l'IA est aussi bonne que ta demande, et tu ne gardes jamais un code que tu ne comprends pas. C'est pour ça qu'on apprend la base à la main avant.

Checklist

  • Je sais ce que font HTML, CSS et JavaScript.
  • J'écris une balise avec un attribut.
  • Je connais le squelette d'une page et le rôle de <head> et <body>.
  • J'utilise les balises sémantiques (header, main, section, footer…).
  • J'inspecte une page avec F12.
  • J'ai ajouté ma première section au site.
  • J'ai écrit un prompt précis (contexte, objectif, contraintes, critère de réussite) et relu le code de l'IA.

Journal et commit

Entrée dans journal.md, puis un commit, par exemple git commit -m "Ajoute la section Pourquoi je me forme sur l'accueil", puis git push.
