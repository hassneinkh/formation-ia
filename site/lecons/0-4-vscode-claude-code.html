Leçon 0.4 · environ 2 h

VS Code et Claude Code : bien travailler avec l'IA

Objectif : utiliser VS Code pour lire et écrire du code, et utiliser Claude Code comme un coach, pas comme une machine à copier-coller.

Partie 1 — VS Code, ton atelier

VS Code est un éditeur de code : un traitement de texte spécialisé, gratuit, déjà installé sur ton PC.

Ouvrir ton projet

cd ~/Documents/formation-ia
code .        # ouvre VS Code sur le dossier actuel (le point = « ici »)

Les 4 zones à connaître

ZoneÀ quoi elle sertRaccourci
ExplorateurL'arborescence de tes fichiers (à gauche)Ctrl+Shift+E
ÉditeurLà où tu écris le code (au centre)
Terminal intégréUn terminal directement dans VS CodeCtrl+ù (clavier AZERTY)
Contrôle de sourceGit avec des boutons : voir les modifications, faire un commitCtrl+Shift+G

Choisis Git Bash dans le terminal de VS Code : ouvre le terminal, clique sur la petite flèche ˅ à côté du +, puis Git Bash. Tu retrouves les mêmes commandes qu'en leçon 0.1.

Extensions utiles

Onglet Extensions (Ctrl+Shift+X), puis installe :

  • Live Preview (Microsoft) : affiche ta page web à côté du code et la met à jour quand tu enregistres.
  • French Language Pack (facultatif) : VS Code en français.

Raccourcis d'or : Ctrl+S (enregistrer), Ctrl+P (ouvrir un fichier par son nom), Ctrl+F (chercher).

Partie 2 — Claude Code, ton coach

Comment il fonctionne

Contrairement à Claude Chat, Claude Code travaille directement dans ton dossier : il lit tes fichiers, peut les modifier et lancer des commandes. Il te demande la permission pour les actions importantes. Tu restes le chef : lis ce qu'il propose avant d'accepter.

Les fichiers qui lui donnent le contexte

FichierRôle
CLAUDE.mdLes règles permanentes : qui tu es, le mode coach, les conventions. Lu à chaque session. (La commande /init en crée un automatiquement dans un projet existant.)
PROGRESSION.mdOù tu en es. Claude le lit au début et le met à jour à la fin.

Le mode plan

Pour une grosse tâche, active le mode plan : Claude réfléchit et te propose un plan sans rien modifier. Tu valides, puis il agit. C'est exactement comme ça qu'on a créé cette formation.

Bien formuler une demande

Une bonne demande contient 3 choses : le contexte, l'objectif et les contraintes.

❌ Vague✅ Précis
« Fais-moi une page. » « Je suis à la leçon 1.1. Je veux créer exercices/module-1-1/ma-page.html qui me présente. Ne l'écris pas pour moi : donne-moi juste la liste des balises dont j'aurai besoin. »
« Ça marche pas. » « Dans index.html, mon lien vers le parcours ne fonctionne pas. Voici ce que j'ai écrit : … Donne-moi un indice. »

3 règles de sécurité :

  • Ne colle jamais un mot de passe ou une clé API dans une conversation.
  • Lis toujours ce que Claude propose de modifier ou d'exécuter.
  • Si tu ne comprends pas un code, demande : « Explique-moi cette ligne. » Ne garde jamais un code que tu ne comprends pas.

Claude Code ou Claude Chat ?

  • Claude Code : écrire du code, le relire, lancer des commandes, faire avancer le site.
  • Claude Chat : réviser un concept, faire des fiches, réfléchir à une idée de business.

Exercices

Exercice 1 — Prendre VS Code en main

  1. Ouvre le projet avec code ..
  2. Ouvre site/css/style.css et lis la section 1 « Variables ».
  3. Change la valeur de --accent (par exemple #e11d48), enregistre, puis rafraîchis le site dans ton navigateur. Que se passe-t-il ?
  4. Ouvre l'onglet Contrôle de source : VS Code montre ta modification. Remets la couleur d'origine, ou garde-la si elle te plaît !

Exercice 2 — Demander une explication

Ouvre site/js/main.js. Choisis une ligne que tu ne comprends pas et demande à Claude Code de te l'expliquer avec un exemple de la vie quotidienne.

Exercice 3 — Écrire 3 bonnes demandes

Dans exercices/module-0-4/mes-prompts.md, écris 3 demandes que tu pourrais faire à Claude Code pendant la leçon 1.1, en respectant contexte, objectif et contraintes. Demande ensuite à Claude de les noter sur 10.

Checklist

  • J'ouvre mon projet dans VS Code et j'utilise son terminal.
  • Je sais à quoi servent CLAUDE.md et PROGRESSION.md.
  • Je sais quand utiliser le mode plan.
  • Je formule des demandes précises (contexte, objectif, contraintes).
  • Je lis toujours ce que Claude propose avant d'accepter.

Journal et commit

Entrée dans journal.md, puis add → commit → push. Tu peux essayer de le faire avec les boutons de l'onglet Contrôle de source de VS Code.
