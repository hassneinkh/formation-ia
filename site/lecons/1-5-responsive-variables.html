Leçon 1.5 · environ 2 h 30

CSS : responsive et variables

Objectif : faire une page qui s'adapte du téléphone à l'ordinateur, tester tous les écrans avec F12, et organiser ton design avec des variables CSS, mode sombre compris.

Notion 1 — Pourquoi le « responsive » ?

Plus de la moitié des visites web se font sur téléphone, et Google classe les sites d'abord selon leur version mobile. Un site responsive s'adapte à la largeur de l'écran.

Les 3 bases à toujours avoir

<meta name="viewport" content="width=device-width, initial-scale=1.0">   <!-- sans lui, le téléphone affiche une version miniature -->

img { max-width: 100%; height: auto; }   /* une image ne dépasse jamais son conteneur */
.conteneur { max-width: 1080px; margin: 0 auto; padding: 0 20px; }   /* largeur max + marges de sécurité */

Tester avec F12

F12, puis l'icône 📱 (Toggle device toolbar, ou Ctrl+Shift+M) : choisis un modèle de téléphone ou tire sur le bord pour changer la largeur.

Notion 2 — Les media queries

C'est quoi ?

Un bloc de règles qui ne s'applique que si une condition est vraie, le plus souvent une largeur d'écran.

Comment l'écrire : « mobile d'abord »

/* 1. Styles de base : pour le TÉLÉPHONE (le plus simple, une colonne) */
.colonnes { display: grid; gap: 16px; }

/* 2. Dès 768px de large (tablette) : 2 colonnes */
@media (min-width: 768px) {
  .colonnes { grid-template-columns: 1fr 1fr; }
}

/* 3. Dès 1024px (ordinateur) : 3 colonnes */
@media (min-width: 1024px) {
  .colonnes { grid-template-columns: 1fr 1fr 1fr; }
}

Pourquoi « mobile d'abord » ? On part du plus simple et on ajoute pour les grands écrans. Le code est plus court et le téléphone charge moins de règles. (Le site de formation utilise parfois l'inverse, max-width, pour de petits ajustements : les deux existent.)

  • Une largeur fixe (width: 900px) sur un bloc : sur téléphone, la page déborde et défile sur le côté. Préfère max-width.
  • Oublier la balise viewport : les media queries semblent ne pas marcher sur téléphone.

Notion 3 — Les variables CSS

C'est quoi ?

Une valeur nommée, définie une fois et réutilisée partout. Change-la à un endroit : tout le site suit. C'est la base d'un design system.

Comment l'écrire

:root {                       /* :root = toute la page : les variables sont disponibles partout */
  --accent: #4f46e5;          /* une variable commence par deux tirets */
  --rayon: 14px;
}
.bouton {
  background: var(--accent);  /* var(--nom) pour l'utiliser */
  border-radius: var(--rayon);
}

Le mode sombre

@media (prefers-color-scheme: dark) {
  :root {
    --fond: #121214;          /* on redéfinit SEULEMENT les variables */
    --texte: #ececf1;
  }
}

Tu reconnais site/css/style.css ? C'est exactement ça. Toutes les règles utilisent var(--…), donc le mode sombre ne demande qu'un bloc.

Quand utiliser une variable ?

Pour toute valeur répétée ou qui fait partie de l'identité du site : couleurs, arrondis, ombres, largeur max, polices.

Exercices

Ce qu'on attend de toi : réécrire exercices/module-1-1/style.css pour que :

  • toutes les couleurs soient des variables dans :root (au moins --fond, --surface, --texte, --accent) ;

Exercice 2 — Le détective du débordement

Ce qu'on attend de toi : trouver pourquoi cette page défile horizontalement sur téléphone, et corriger.

.bandeau { width: 1200px; padding: 20px; }
.photo { width: 800px; }
Correction 
.bandeau { max-width: 1200px; padding: 20px; }   /* max-width : peut rétrécir */
.photo { max-width: 100%; height: auto; }

Une largeur fixe plus grande que l'écran force le défilement. max-width donne une limite sans empêcher de rétrécir.

Questions pour vérifier que tu as compris

1. Que fait @media (min-width: 768px) { … } ?

Réponse

Il applique les règles à l'intérieur seulement quand l'écran fait au moins 768px de large.

2. Pourquoi le mode sombre du site ne demande-t-il qu'un seul bloc ?

Réponse

Parce que toutes les règles utilisent des variables : il suffit de redéfinir les variables, pas les règles.

Checklist

  • J'ai toujours la balise viewport, des images en max-width: 100%.
  • J'écris des media queries « mobile d'abord ».
  • Je teste avec F12 en mode appareil.
  • Je crée et j'utilise des variables CSS, et je fais un mode sombre.
