Hassnein, 19 ans, futur builder IA

Ici, je raconte qui je suis, pourquoi je me forme, et comment fonctionne cette formation.

Qui je suis

Je m'appelle Hassnein, j'ai 19 ans et je travaille pour moi-même. Je suis étudiant en e-business et je veux apprendre à coder.

Je pars de zéro : avant cette formation, je n'avais jamais écrit une ligne de code. Tout ce que tu vois sur ce site, je l'apprends en le construisant.

Pourquoi je me forme

Je veux devenir capable de créer moi-même des sites web, des applications mobiles et des produits qui utilisent l'intelligence artificielle.

Mon objectif final : lancer mon propre business dans le digital, en sachant construire mes outils au lieu de dépendre des autres.

La formation

Une formation sur mesure d'environ 11 à 13 mois, à raison de 10 heures ou plus par semaine, construite avec Claude comme coach.

Les 9 phases

  • Phase 0 — Démarrage : terminal, Git, GitHub, VS Code et Claude Code.
  • Phase 1 — Fondations du web : HTML, CSS et JavaScript.
  • Phase 2 — Données et API : JSON, fetch, branches Git.
  • Phase 3 — Dev web moderne : TypeScript, React, Next.js, Supabase.
  • Phase 4 — Construire avec l'IA : prompts, specs, générateurs, design et vidéo.
  • Phase 5 — Mettre l'IA dans mes produits : API Claude, RAG, agents, automatisations.
  • Phase 6 — SEO et marketing digital.
  • Phase 7 — Application mobile avec React Native et Expo.
  • Phase 8 — Business et lancement : MVP, Stripe, cadre légal belge.

Deux fils rouges

GitHub : chaque étape est sauvegardée dans un commit, et mon historique devient mon CV.

Construire avec l'IA : je code d'abord à la main pour comprendre, puis je refais avec l'IA et je compare.

Ma méthode

Chaque leçon suit les mêmes étapes :

  1. Je lis une explication courte, avec des exemples.
  2. Je fais les exercices moi-même, avec des indices si je bloque.
  3. J'ajoute une fonctionnalité à ce site.
  4. Je refais le travail avec l'IA et je compare.
  5. J'écris dans mon journal et je fais un commit sur GitHub.

Ce site est donc à la fois mon cours et mon premier vrai projet. Pour voir où j'en suis, va sur la page Parcours.
