Comment ça marche

1. Une explication courte

10 à 20 minutes de lecture, avec des exemples concrets.

2. Je pratique

J'écris le code moi-même. Claude me donne des indices, pas les solutions.

3. J'améliore ce site

Chaque module, j'ajoute une vraie fonctionnalité à ma plateforme.

4. Je refais avec l'IA

Je demande la même chose à l'IA, je compare et je relis. J'apprends à bien la guider.

5. Je sauvegarde sur GitHub

Un commit à chaque étape : mon historique devient mon CV.
