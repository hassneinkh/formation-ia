# Formation IA — de débutant à builder
Mon profil git hub

Ma formation personnelle pour apprendre à créer des sites web, des applications mobiles
et des produits IA, maîtriser le SEO et GitHub, puis lancer mon propre business.

Le dossier `site/` est à la fois **ma plateforme de cours** et **mon premier vrai projet**.

## Voir le site
Double-clique sur `site/index.html`.

## Feuille de route (environ 11 à 13 mois à 10 h+ par semaine)

| Phase | Thème | Durée | Livrable |
|---|---|---|---|
| 0 | Démarrage : terminal, Git, GitHub, VS Code, Claude Code | 1 sem. | Premier dépôt GitHub |
| 1 | Fondations du web : HTML, CSS, JavaScript | 5–6 sem. | Site en ligne sur GitHub Pages |
| 2 | JavaScript intermédiaire et données (JSON, API, async) | 3–4 sem. | Mini-projet API |
| 3 | Dev web moderne : TypeScript, React, Next.js, Tailwind, Supabase | 6–8 sem. | Site v2 sur Vercel, avec comptes |
| 4 | **Construire avec l'IA** : prompts pour le code, specs, Claude Code, générateurs (Lovable, v0, Bolt), design, vidéo, qualité | 7–8 sem. | Un site pro construit de A à Z avec l'IA |
| 5 | **Mettre l'IA dans tes produits** : API Claude, chat, RAG, agents, automatisations (n8n/Make) | 5–6 sem. | Coach IA intégré au site |
| 6 | SEO et marketing digital (avec l'IA) | 4 sem. | Blog SEO et rapport de trafic |
| 7 | App mobile : React Native + Expo | 6 sem. | App compagnon sur mon téléphone |
| 8 | Business et lancement : validation, MVP, Stripe, cadre légal belge | 4–6 sem. | Un vrai produit lancé |

### Fil rouge « Construire avec l'IA »
Dès la Phase 1, chaque leçon se termine par **« 🤖 Refais-le avec l'IA »** :
1. Je code d'abord à la main, pour comprendre la base.
2. Je demande la même chose à Claude Code, avec un prompt précis.
3. Je compare les deux versions et je relis le code de l'IA ligne par ligne.
4. Je note dans mon journal le prompt qui a le mieux marché.

Ma bibliothèque de prompts grandit ainsi à chaque leçon, et la Phase 4 en fait une méthode complète.

### Fil rouge GitHub
| Phase | Compétences Git/GitHub |
|---|---|
| 0 | `init`, `add`, `commit`, `status`, `log`, compte GitHub, `push` |
| 1 | Messages de commit, `.gitignore`, README en Markdown, GitHub Pages |
| 2 | Branches, `merge`, conflits, revenir en arrière |
| 3 | Pull Requests, Issues, GitHub Projects, déploiement relié à GitHub |
| 4 | GitHub Actions, secrets, reprendre sur GitHub le code d'un générateur IA |
| 5–7 | Releases, tags, protection de `main` |
| 8 | Profil GitHub vitrine, open source, travail en équipe |
